## 📖 使用方法

### 1. 创建角色

1. 打开应用：http://localhost:3000
2. 点击左侧边栏的 **👤 角色** 按钮
3. 点击右上角的 **+** 按钮
4. 填写角色信息：
   - **角色名称**：例如"女主角-小美"
   - **角色描述**：详细描述外貌、性格、服装等
     ```
     一位25岁的现代都市女性，黑色长发，穿着商务西装，
     气质优雅，眼神坚定，具有职业女性的自信感
     ```
   - **参考图片**：上传 1-5 张角色参考图
   - **标签**：添加标签如"女性"、"25岁"、"现代"、"商务"

5. 点击 **创建** 保存角色

### 2. 使用角色生成内容

#### 方法 A：从角色库拖拽到画布

1. 在角色库中找到想要使用的角色
2. 点击角色卡片底部的 **添加到画布** 按钮
3. 角色节点会自动添加到画布上

#### 方法 B：直接在画布添加角色节点

1. 右键点击画布空白处
2. 选择 **角色** 选项
3. 创建角色节点后，点击节点选择角色

#### 方法 C：快速连接

1. 创建任意生成节点（如"文生图"）
2. 鼠标悬停在节点的输出点
3. 点击 **+** 按钮 → 选择 **角色**

### 3. 连接角色节点到生成节点

```
[角色节点] ──→ [文生图节点]
              ↓
           生成结果
```

**工作流程：**

1. 将角色节点的右侧输出点连接到生成节点的左侧输入点
2. 在生成节点中输入提示词（例如："在办公室工作"）
3. 点击 **生成** 按钮
4. 系统会自动：
   - 将角色描述注入到提示词前面
   - 将角色参考图传递给 AI 模型
   - 生成符合角色特征的图片

**实际提示词示例：**

```
原始输入：在办公室工作
实际发送：一位25岁的现代都市女性，黑色长发，穿着商务西装，
         气质优雅，眼神坚定，具有职业女性的自信感。在办公室工作
```

### 4. 管理角色

- **编辑角色**：点击角色卡片右上角的 ✏️ 图标
- **删除角色**：点击角色卡片右上角的 🗑️ 图标
- **搜索角色**：在角色库顶部的搜索框输入关键词
- **查看角色**：点击画布上的角色节点查看详细信息

## 💡 使用技巧

### 1. 编写高质量的角色描述

**好的描述示例：**

```
一位30岁的男性冒险家，棕色短发，浓密的胡须，
穿着卡其色探险服和皮革背心，眼神锐利，
肤色因长期户外活动而呈现健康的古铜色，
右手佩戴一块老式机械表，整体风格粗犷而专业
```

**不好的描述：**

```
一个男人
```

### 2. 选择合适的参考图

- ✅ 选择清晰、高质量的照片
- ✅ 多角度展示（正面、侧面、全身）
- ✅ 光线充足、背景简洁
- ❌ 避免模糊、遮挡的照片
- ❌ 避免过度修图的照片

### 3. 使用标签组织角色

建议标签类别：

- **性别**：男性、女性
- **年龄段**：儿童、青年、中年、老年
- **风格**：现代、古风、科幻、奇幻
- **职业**：医生、教师、战士、法师
- **情绪**：开朗、冷酷、温柔、严肃

### 4. 组合多个节点

```
[文本节点：场景描述] ──┐
                      ├──→ [文生图节点] → 生成结果
[角色节点] ───────────┘
```

## 🔧 技术细节

### 数据库表结构

```sql
CREATE TABLE characters (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL UNIQUE,
  description TEXT NOT NULL,
  reference_images TEXT NOT NULL,  -- JSON array
  tags TEXT NOT NULL,              -- JSON array
  lora_model_url TEXT,             -- 预留LoRA字段
  lora_weight REAL DEFAULT 0.8,
  lora_status TEXT DEFAULT 'none',
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);
```

### API 响应格式

```typescript
{
  success: true,
  data: {
    id: "uuid",
    name: "角色名称",
    description: "角色描述",
    referenceImages: ["url1", "url2"],
    tags: ["标签1", "标签2"],
    loraModelUrl: null,
    loraWeight: 0.8,
    loraStatus: "none",
    createdAt: 1234567890,
    updatedAt: 1234567890
  }
}
```

## ❓ 常见问题

**Q: 角色节点必须连接到生成节点吗？**
A: 不是必须的，但连接后才能自动应用角色特征。

**Q: 可以同时使用多个角色吗？**
A: 当前版本支持单个角色输入，多角色场景将在后续版本支持。

**Q: 参考图会上传到哪里？**
A: 参考图通过 `/api/upload/image` 上传到配置的 OSS 服务。

**Q: 删除角色后图片会自动删除吗？**
A: 当前版本不会自动删除 OSS 上的图片，这是未来优化项。

**Q: 角色描述用中文还是英文？**
A: 建议使用中文，系统会根据需要处理语言转换。
