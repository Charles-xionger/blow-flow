# 脚本创作

脚本节点负责选择指令、模型、参考和创作要求。点击“生成文本”立即创建相连的文本节点，正文在文本节点中流式显示。自由创作、写剧本和提取素材各输出一个文本节点；拆分镜按镜头输出多个独立文本节点。没有发布步骤、历史版本列表或编辑稿面板。重新生成会创建另一份文本，不覆盖之前的结果。

指令分为自由创作、写剧本、拆分镜和提取素材；卡片展示用途，“查看／调整指令”可以展开编辑指令正文。

拆分镜先创建“镜头 001”，模型每输出一个新镜头标题，就创建下一个相连的文本节点；每个节点只展示对应镜头的正文。节点依次放在脚本右侧空闲位置。每个镜头包含场景、景别与构图、人物行动、镜头运动、对白、声音和建议时长。已有的完整分镜文稿不自动拆分；重新发起拆分镜使用新规则。模型未按约定格式输出时保留原文并提示失败，不自动重试。

## 运行

使用 `pnpm dev:all` 启动 Web 和后台服务；已有 Web 时单独运行 `pnpm script:worker`。两者必须共享 `DATABASE_PATH`、工作目录和服务端模型配置。Ark 使用 `ARK_API_KEY`，Gemini 使用平台配置或 `GOOGLE_API_KEY`／`GEMINI_API_KEY`。修改代码或密钥后重启 worker。

同一脚本节点最多一个活动任务，默认脚本并发 5（`SCRIPT_CONCURRENCY`）。创建请求幂等；关闭页面后后台继续。当前执行上限为 180 秒，超时保留已经收到的文字，不自动重试。状态区分连接、等待、思考和正文输出，不把思考内容写入剧本。

## 文本结果

活动任务中结果文本只读，停止或结束后可以直接编辑。完成和部分结果自动保存到文本正文。点击停止会等待后台确认；异常和停止不会自动创建第二次模型调用。删除结果后任务不会恢复节点；复制／导入不会继续原任务。脚本到文本的线记录来源，后续修改脚本要求不改写已有文本。

下游使用生成的文本节点。文本落库后触发正常输入变化提示，不会自动运行下游节点。

## 同步与恢复

任务列表与流式事件查询只读取任务状态；过期执行恢复和结果落库由后台 worker 负责。画布通过统一版本通知同步新增镜头及正文，单个文本节点不再各自触发画布刷新。终态正文每批最多保存 20 个镜头，批次提交后释放写锁；批次回执支持中断后继续保存，不覆盖人工修改或复活已删除节点。

## 旧数据

旧创意／分镜节点按既有迁移规则保留提示词、位置、已有文本和原数据档案，不调用模型。先前脚本任务中已保存的正文和编辑稿会转为文本结果，已存在的发布文本保持原样，不再要求发布。旧任务、编辑稿表保留，不删除作品。

助手可创建并连接脚本节点，通过 `read_script` 查看任务和结果文本身份。已移除 `publish_script`；普通文本仍遵守已有内容所有权规则。

本次变更未运行自动测试或真实模型验证；类型、lint 和静态检查不等于浏览器端到端验收。产品决定见 [ADR 0013](adr/0013-script-streams-to-text-nodes.md)。
