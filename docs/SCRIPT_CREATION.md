# 脚本创作与旧项目迁移

脚本节点统一承担自由创作、剧本、分镜文稿与素材描述。它没有可消费的输出端口；明确发布后的文本节点才是下游参考。旧创意描述／分镜生成菜单、节点组件和 `/api/storyboard` 已移除。

## 运行条件

Web 与 `pnpm script:worker` 必须持续运行并共用 `DATABASE_PATH`、工作目录与服务端配置。开发可使用 `pnpm dev:all`；创作助手还需要 agent worker。脚本并发由 `SCRIPT_CONCURRENCY` 控制（默认 5，范围 1–20）。Ark 使用服务端 `ARK_API_KEY`；Gemini 使用已保存的平台配置或 `GOOGLE_API_KEY`／`GEMINI_API_KEY`。修改密钥后重启 Web 与相应 worker。密钥不进入画布、输入快照或助手目录。

DeepSeek V4 Pro 仅接受文本参考；图片参考请选择支持图片的模型（例如 Doubao Seed 2.1 Pro）。图片需有可读取的原始素材地址，临时预览图不作为输入。配置、能力或素材校验失败时不会静默换模型。迁移保留原模型选择；已失效或不兼容的旧模型需由用户在控制台重新选择。

## 迁移策略

同一个纯转换器用于服务端读取与写入、本地 IndexedDB 草稿、旧 localStorage 草稿、JSON 导入、恢复副本及历史。打开旧项目即可看到脚本结构，后续正常版本检查写入使其持久化；回收站项目恢复后也走同一路径，永久删除的项目不会被迁移复活。

旧节点保留 ID、位置、分组、提示词及模型。已有相连文本保留正文与用户修改，不按相似文字匹配或覆盖。没有现存文本、且历史中也没有文本产物关联证据时，存储的镜头描述逐条成为确定身份的文本节点；没有描述不会补写内容。有部分文本或存在历史删除证据时，不猜测缺失镜头，保留原始镜头数据供查看、复制。不会调用模型或重新生成素材。

脚本控制台的“旧创作内容迁移档案”保存旧节点内容、原输出连线和输出节点身份。被改写的引用另存 `legacyPromptArchive`。原本从旧节点到其文本产物的线改为档案来源关系，不成为未发布脚本的输出。其他下游连接改为引用真实文本产物；多个文本按原连接顺序展开为有效连线及引用，去重并避免循环。无法建立的连接留在原档案中供人工核对，不制造聚合正文。与旧节点无关的连线不受迁移改写。

活动撤销／重做记录按旧时间线逐步转换，始终恢复新结构；原始操作日志、历史媒体与档案保留。迁移不会自动执行任何历史任务。版本列表按项目和节点持久任务身份查询，不依赖画布历史中的临时任务指针。复制、导入和恢复到新项目清除 `pendingScript`、`pendingScriptPublish`、`scriptTaskId`、`scriptSource`，已有文本正文保留；原项目的版本和发布权限不会附着到副本。

本地尚未确认的保存请求保持原 requestId 和原 payload 重发，服务端以原 payload 计算幂等摘要，再转换保存内容；确认后以新 requestId 发送升级草稿。迁移不会偷偷改写进行中的请求。如果远端与本地无法安全合并，沿用现有冲突恢复／另存副本流程。

## 创作助手

助手通过 `edit_canvas` 的同一语义服务创建和连接脚本，通过 `canvas_models` 发现服务端已配置的语言模型，`read_script` 查看持久版本和发布目标。`publish_script` 使用与控制台相同的发布服务，只接受完成且当前选用的版本及准确编辑稿修订。

助手发布必须得到持久确认，展示待发布正文及更新目标的当前文本。确认仅授予这一份发布；事务内同时检查助手执行租约、确认身份、目标权限和目标修订。目标被改写或删除时仍返回冲突，不通过普通编辑工具绕过发布保护。默认新建文本，更新原文本是显式选择。不会自动连续运行“剧本→分镜→素材”整条链。

## 待人工执行的真实链路

1. 新建文本节点写入创意，连接脚本，选择“生成剧本”和已配置的语言模型。
2. 发起生成，检查真实状态和持久正文；编辑完成稿并发布为剧本文本。
3. 将剧本文本连接到第二个脚本，选择“生成分镜”，生成、编辑并发布分镜文稿。
4. 核对旧版本保留、参考来源、更新已发布文本后的冲突提示和下游输入变化提示。独立检查停止、刷新恢复、worker 丢失后的中断状态，以及无效参考在提交前被阻止。

以上是部署后的人工联调步骤，尚未执行。此次遵循用户要求，未编写或运行自动测试，未发起真实供应商或付费接口调用；类型与 lint 检查不能代替浏览器交互、迁移回归和真实平台验收。生产不包含原型模拟结果、固定演示流程或布局对比器。
