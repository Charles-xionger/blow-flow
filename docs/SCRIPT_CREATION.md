# 脚本创作

脚本节点负责选择指令、模型、参考和创作要求。点击“生成文本”立即创建相连的文本节点，正文在文本节点中流式显示。自由创作、写剧本和提取素材各输出一个文本节点；分镜与资产采用固定 Workflow，结果直接显示在脚本节点内，不新建结果节点。没有发布步骤、历史版本列表或编辑稿面板。自由创作、写剧本重新生成会创建另一份文本；分镜始终在脚本节点内部展示。

控制台提供自由创作、写剧本、分镜与资产三个入口；分镜与资产一次整理镜头、角色、场景、道具和视频提示词。旧独立素材提取节点保留原指令，可主动切换到分镜与资产。参考内容与指令设置默认折叠，创作要求和分镜配置直接展示，底部固定模型选择与生成入口。指令可恢复默认，输出约束随配置更新并可展开查看。

拆分镜默认总时长 60 秒、最多 5 个镜头，每镜不超过 15 秒，可在脚本控制台调整时长和数量上限，或选择 30／60／120 秒快捷配置；无法满足单镜时长限制时就地提示并禁止新提交，可一键调整为所需镜头数。指令要求合并同场景连续动作，优先删减支线而非增加镜头；输出后检查镜头数量、单镜时长与合计时长。超出约束的结果保留并提示调整，不自动重试。

分镜模式的脚本节点展示产物摘要、阶段状态、完成百分比与打开入口；弹窗分为确认镜头、准备资产、视频提示词。镜头规划校验完成后出现镜头列表，后续按批次补齐细节；整个流程完成后可编辑、增删；资产按角色、场景和道具汇总，主动点击才创建对应图片节点。图片在现有节点中生成，结果同步显示到资产卡片。视频提示词随分镜生成并可编辑，当前没有自动批量生图或生视频。

已有逐镜头文本节点保留，不自动删除或改写；新提交的拆分镜任务使用集中展示。

## 运行

使用 `pnpm dev:all` 启动 Web 和后台服务；已有 Web 时单独运行 `pnpm script:worker`。两者必须共享 `DATABASE_PATH`、工作目录和服务端模型配置。Ark 使用 `ARK_API_KEY`，Gemini 使用平台配置或 `GOOGLE_API_KEY`／`GEMINI_API_KEY`。修改代码或密钥后重启 worker。

同一脚本节点最多一个活动任务，默认脚本并发 5（`SCRIPT_CONCURRENCY`）。创建请求幂等；关闭页面后后台继续。普通文本任务上限为 180 秒；新分镜流程每次模型调用有独立时限（连接 20 秒、首正文 60 秒、停滞 30 秒、总计 120 秒），一轮流程预算 10 分钟，不自动重试。状态区分连接、等待、思考和正文输出，不把思考内容写入剧本。

## 分镜 Workflow

镜头规划 → 资产整理 → 分批细化（每批最多 2 镜，并发最多 2 批）→ 本地组装提示词。模型经通用层调用，无 Critic。阶段独立校验并保存检查点；失败后相同输入点击继续，跳过已完成步骤。修改输入会从头执行新任务，但不会新增画布节点。进度按规划 20%、资产 20%、镜头细化 50%、提示词 10% 计算，全部完成才显示 100%。失败和停止时可以查看、下载检查点，完成后才开放结果编辑。

## 文本结果

活动任务中结果文本只读，停止或结束后可以直接编辑。完成和部分结果自动保存到文本正文。点击停止会等待后台确认；异常和停止不会自动创建第二次模型调用。删除结果后任务不会恢复节点；复制／导入不会继续原任务。脚本到文本的线记录来源，后续修改脚本要求不改写已有文本。

下游使用生成的文本节点。文本落库后触发正常输入变化提示，不会自动运行下游节点。

## 同步与恢复

任务列表与流式事件查询只读取任务状态；过期执行恢复和结果落库由后台 worker 负责。画布通过统一版本通知同步新增镜头及正文，单个文本节点不再各自触发画布刷新。终态正文每批最多保存 20 个镜头，批次提交后释放写锁；批次回执支持中断后继续保存，不覆盖人工修改或复活已删除节点。

## 旧数据

旧创意／分镜节点按既有迁移规则保留提示词、位置、已有文本和原数据档案，不调用模型。先前脚本任务中已保存的正文和编辑稿会转为文本结果，已存在的发布文本保持原样，不再要求发布。旧任务、编辑稿表保留，不删除作品。

助手可创建并连接脚本节点，通过 `read_script` 查看任务和结果文本身份。已移除 `publish_script`；普通文本仍遵守已有内容所有权规则。

本次变更未运行自动测试或真实模型验证；类型、lint 和静态检查不等于浏览器端到端验收。产品决定见 [ADR 0013](adr/0013-script-streams-to-text-nodes.md)。
