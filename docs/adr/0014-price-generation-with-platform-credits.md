# 使用版本化平台积分价格并在结果交付后结算

生成任务不把 RunningHub 积分或字节账单直接转嫁给用户，而是根据预计供应商成本、定价汇率和按模型配置的目标毛利率发布不可变的产品价格版本，并以“100 平台积分对应 1 美元标准价值”作为内部定价锚点。用户确认生成时按价格快照冻结平台积分，只有结果保存并可交付后才结算；未交付时返还原积分批次，供应商已经产生的费用作为失败成本由平台承担。这样用户可以在生成前获得跨供应商一致且可预测的任务价格，代价是平台承担单次成本波动和供应商失败风险，并必须分别保存供应商用量、供应商成本、价格快照与不可变积分流水。
