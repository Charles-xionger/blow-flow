# 模型统一表达生成能力，平台差异由后端封装

产品的模型目录同时容纳厂商模型和封装好的生成工作流，前端使用统一的模型选择与生成操作；后端保留接入类型及各自的参数映射，避免业务界面依赖平台协议。平台连接由管理员统一配置并供模型引用，首版使用者选择模型而不各自配置平台凭据。

首批以两个 RunningHub 工作流可用为交付范围，不以 Gemini 或第二个平台的真实接入为前置条件；跨平台扩展能力仍需在后续接入其他平台时验证。允许前端补充由模型能力驱动的通用输入及任务状态展示，平台专属调用逻辑留在后端。首版通过后端配置文件登记工作流及参数映射，可视化导入和映射编辑器留待后续评估。

首批仅新增 RunningHub 模型使用新中间层；已有模型保持原调用行为，现有文本调用本次不迁移。模型层为文本、图片与视频保留能力分类，实际文本接入及跨平台兼容性在后续迁移中验证。

后续接入火山引擎官方 Seedream 5.0 Pro，覆盖画布文生图、图生图与创作助手，支持最多十张参考图，每次生成一张结果。尺寸使用 1K、1.5K、2K 档位与画幅组合，默认 2K，按该模型的官方规则换算；不沿用 Krea2 的短边算法。

Seedream 与现有后台任务中的 Gemini 生图共用同步图片生成函数接口，由各平台适配器处理请求参数与响应解析，持久化任务层统一负责排队、生成确认和产物保存。同协议模型通过配置扩展，其他协议增加适配器；RunningHub 保留异步提交与查询路径，旧图片接口保持兼容。本次不将所有平台强行改为同一提交／查询协议，以保留已有任务恢复语义。

Seedream 首次接入开放提示词、参考图上传与排序、尺寸档位和画幅，以及高级设置中的提示词优化（标准／快速，默认标准）、图片格式（PNG／JPEG，默认 PNG）、可见水印（默认关闭）和透明背景（默认关闭）。透明背景仅在单张带透明通道参考图且输出 PNG 时允许；参数随节点保存，创作助手使用相同能力与校验。图层拆分、坐标／框选／箭头局部编辑留待后续单独接入。官方能力与参数依据为[火山方舟图片生成 API](https://console.volcengine.com/ark/region:cn-beijing/docs/image-generation-api)，具体模型标识为 `doubao-seedream-5-0-pro-260628`。

Seedream 5.5 作为同一火山方舟图片协议的新模型加入画布模型目录，保留 5.0 Pro 以兼容已有项目。其模型标识为 `doubao-seedream-5-5-261028`，普通生图继续支持最多十张参考图、1K／1.5K／2K 档位与单张输出。它仅开放标准提示词优化，并允许文生图或图生图直接生成透明 PNG，不再要求单张带 Alpha 的参考图。图层拆分、富文本 OCR 和多轮精准编辑仍留待独立产品设计；不因新模型上线而在现有单图节点中隐式开放。依据为[官方 Seedream 5.5 教程](https://docs.volcengine.com/docs/ark/seedream-5-5?lang=zh)与[图片生成 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)。

首批图片采用用户的 Krea2 工作流，视频采用用户修正后的 H3 工作流；官方 MiniMax H3 标准 API 留作后续选项。此选择取代此前优先官方 API 的决定，因为用户要求实际低分辨率生成，而当前官方注册表只声明 2K。H3 接入范围更新为完整参考能力，取代此前先以一张参考图验证的范围：支持最多九张参考图片，以及参考视频和音频，不将导出文件中已连接的素材数量固化为产品上限。参考素材按类型编号并允许调整顺序，后端按确定顺序提交；视频、音频数量及格式限制以核实后的节点和平台契约为准。

H3 默认保留工作流生成的声音，首版不增加输出静音开关。目标时长沿用工作流原生帧数对齐规则，前端显示预计实际时长，不在生成后额外裁剪到目标秒数，以保留原工作流的音视频输出。

H3 在现有图生视频节点中提供参考素材面板：图片和视频可从画布连入，图片、视频和音频均可直接上传；素材可编号、排序与移除，提示词可插入对应引用。参考视频默认使用原声，并允许逐段关闭；无音轨的视频只参考画面。视频原声的引用编号先于独立音频，面板按实际提交顺序展示。此选择复用现有创作入口，不另建一套视频画布。

尺寸、时长、提示词与参考图按具体能力开放，不固定为当前导出的值；允许值仍须来自真实接入契约或经核实的节点定义。视频提供 480p、720p、1080p 的实际生成档位，以修正后的工作流支持及验证为前提；不以 2K 生成后缩小文件代替该要求。前端将分辨率档位与画幅分开选择，后台按工作流要求对齐像素，并在前端显示实际生成尺寸；具体换算规则在核实修正后的工作流后确定。种子不在前端展示，对支持种子的接入在后端生成并记录实际提交值，不对未声明种子参数的 API 编造字段。
