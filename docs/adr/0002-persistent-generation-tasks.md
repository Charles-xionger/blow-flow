# 使用持久化后台任务执行图片与视频生成

图片与视频生成采用后台任务，后端保存任务记录，前端通过统一接口查询状态，避免将生成生命周期绑定到一次页面请求。用户刷新或重新打开画布后应能恢复任务状态并获取结果；平台查询方式由中间层封装。后台执行机制、恢复策略及失败处理的具体规则仍待后续设计确认。

提交结果不明确时标记为待核实，不自动重新提交，避免网络中断造成重复计费。已取得平台任务 ID 的任务继续查询；明确失败后由用户重新生成，创建新任务。

后端服务重启后恢复对已提交任务的查询；恢复依据为持久化的平台任务 ID，不通过重新提交代替恢复。每次生成保存独立的输入快照与结果；节点展示最近一次生成任务的结果，先前任务迟到的结果保留在任务记录中，不覆盖新任务的展示。

首版每个平台连接默认仅执行一个任务，其余任务在本地队列等待；并发数可由后台配置，此默认值不代表平台官方限制。删除节点时取消尚未提交的任务；已提交的任务继续跟踪并保存结果，不重新创建已删除的节点。平台取消能力在核实后另行开放。

生成成功后的产物转存到项目现有 OSS。生成状态与转存状态分开记录；转存失败时保留平台结果及任务 ID，重试下载保存，不重新生成。若平台临时文件过期导致无法转存，明确记录生成成功但结果保存失败，由用户决定是否重新生成，不自动创建付费任务。

查询期限可配置；到期后标记等待超时并停止自动轮询，允许用户继续查询原任务。等待超时不是平台任务失败，状态未明确前仍占用连接的并发名额。继续查询使用原平台任务 ID，不重新提交。
