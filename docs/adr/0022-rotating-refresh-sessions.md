# 用轮换刷新会话延续本地 JWT 登录

Go API 继续签发 15 分钟的 access JWT。管理员与创作者各使用独立的、仅发送到对应认证路径的 HttpOnly、SameSite=Strict 刷新 Cookie；刷新值为随机凭据，数据库只保存其 SHA-256 摘要。刷新在 PostgreSQL 事务中锁定旧会话、吊销旧凭据并创建新凭据，重复使用旧值失败。会话当前有效期为每次轮换后七天；退出吊销当前刷新会话。账户禁用时不能刷新；每次受保护请求仍核对当前账户状态。

刷新保留最初密码验证时的 `auth_time`，不把刷新视为重新认证。ADR-0020 要求的敏感管理操作近期登录窗口因此不会被自动续期绕过。刷新端点只接受同源浏览器请求。Admin 前端在 access token 到期前刷新，并在 401 后最多刷新重试一次；临时网络故障不会删除本地会话。

刷新 Cookie 不返回给 JavaScript，也不交给 Pi Worker。未来 Agent 内部提交使用绑定任务运行的服务令牌，与用户登录会话分开。退出后已签发的 access JWT 最多仍可用到其 15 分钟到期；缩短这一窗口需要另行引入 access token 撤销检查。
