# 账户积分与生成任务创建作为同一 PostgreSQL 事务边界

用户认证、产品计价、平台积分冻结和生成任务创建直接建设在 PostgreSQL 目标架构中，并由 Go API 作为权威写入者在同一事务边界内完成；不在现有 SQLite 中新增一套过渡账本。独立的 `apps/admin` 与用户制作品台共享该 API，均不直接修改业务数据库；现有 TypeScript 生成执行能力在迁移期间通过明确协议领取和更新任务，不能绕过账务边界。此选择增加了首版迁移工作量，但避免跨数据库冻结与建单不一致、Go/TypeScript 双写以及账本上线后的二次迁移；历史无归属资源统一迁移给初始所有者账户并保留原有标识。
