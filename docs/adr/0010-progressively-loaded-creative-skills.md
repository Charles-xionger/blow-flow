# 提供创作技能管理并按需加载技能内容

应用提供独立的创作技能管理与存储，支持上传、删除和列表展示。创作助手使用技能时采用用户要求的 Codex 式渐进加载：先提供技能发现所需的信息，匹配或指定技能后再读取完整指令，配套资源按实际需要读取，避免将所有技能全文注入每次对话。

上传支持单个 `SKILL.md` 和包含该文件及配套资源的 ZIP 包。上传与调用是两个独立阶段：上传只负责校验、存储和登记，不激活技能或加载到模型上下文；调用时才按需读取指令及资源。首版不执行上传包内的脚本，技能通过已有创作工具完成操作。

技能管理是产品能力；数据库、对象存储与本地缓存的分工、技能访问范围，以及删除对运行中任务的影响仍待明确。

首个 Agent 版本先提供随应用内置的创作技能并按需加载；用户上传、删除和列表管理随后交付，不作为首个 Agent 闭环的前置条件。

个人技能库属于当前用户并跨项目使用。管理页和创作助手共享同一个 Skill Registry：管理页可以浏览发现描述、完整指令和资源清单，但浏览不会将技能注入助手上下文；助手仍先读取发现信息，匹配后才读取完整指令，并按需读取资源。内置技能在个人技能库中标记为只读，不能删除、覆盖或编辑。
