# 通过侧栏对话让创作助手操作整张画布

创作助手通过侧栏对话接收要求，能够读取并操作当前项目整张画布；剧本生成和分镜拆分是首批创作能力。选择对话作为助手入口，以便用户跨节点表达和修改创作意图，而不要求将助手的每个步骤组织成画布节点。

服务端按职责拆分，画布操作、创作能力和模型接入通过明确接口协作，使后续新增能力或提供方的影响集中在对应模块。具体运行时集成、持久化与同步协议、Skill 结构和 UI 组件选型仍在设计中，本决定不将讨论中的候选方案视为已确认实现。

创作助手根据用户意图自由组合可用工具与创作技能，不限定为“剧本生成→分镜拆分”的固定流程；剧本和分镜是使用场景，而不是运行时的固定步骤。

在用户要求的范围内，普通节点和连线的创建、修改、移动可直接执行并进入撤销历史；删除已有内容需用户明确要求，否则先询问。图片与视频生成遵循下述批次确认规则。

新增内容默认只布局新增节点，放在相关节点附近的可用位置，不移动已有节点。仅在用户明确要求整理时调整已有节点；用户明确指定选区时只整理选区。布局算法的具体选型仍待评估。

首版纳入已有图片与视频生成能力。创作助手可组织模型与生成参数，但提交生成前必须通过人机交互（HITL）取得用户确认；用户提出生成意图本身不视为对具体生成内容与参数的最终确认。

一次确认覆盖一批明确的生成操作，而非每次工具调用分别确认，例如一次批准基于同一角色参考生成三张场景海报。分析参考素材、选择模型与组织提示词不单独要求批准；后续未获确认的视频生成等操作需另行确认。角色图生成后是否暂停选图取决于任务和用户意图，不规定固定创作流程，以兼顾用户控制与创作效率。具体交互形式仍待设计。

确认后若修改风格、参考素材、数量等生成要求，尚未提交的受影响任务暂停，更新方案并重新取得确认；原批准不覆盖新的要求。已经提交供应商的任务保留，不将修改方案解释为已撤回提交。
