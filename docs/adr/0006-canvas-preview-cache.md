# 画布预览图作为独立、可重建的派生缓存

节点拖动录制出现重复 PNG 解码导致的长时间图层提交，以及素材内容未变时的下游重渲染。画布使用应用服务端按需生成的静态预览图，缓存独立于项目内容、生成任务快照和原始素材；原始素材继续作为生成输入、下载和完整查看的依据，避免展示优化改变创作结果或要求迁移历史项目。

初始预览长边最多 1024 像素，小图不放大，保留透明背景，动图取静态首帧；画布缩放不切回原图。缓存可清除重建，同一原素材与规格复用，源内容或规格变化后失效；预览失败显示可重试状态或当前素材已有的可用预览，由用户主动打开原图，禁止自动原图回退。代价是首次生成等待、服务端处理及缓存存储开销，以及高倍画布缩放下清晰度受限。

采用应用内独立预览接口并声明 Sharp 直接依赖。已安装 Next 16.1.6 的内置图片优化会原样返回动图，并在转换失败时回退原图，公开接口也只限制宽度，无法直接保证上述约束；不将其作为本次预览接口。此处预览是已有图片的展示派生图，不改变 ADR 0002 的生成输入与结果保存语义，也不增加 ADR 0003 范围外的生成中预览事件。

产品边界已在 grill-with-docs 的三轮问答中确认；本 ADR 待最终方案确认后转为 accepted。性能收益须通过生产构建的分项对照验证，不能由架构选择本身推定。
