# 脚本节点只发起生成，独立文本节点流式承载结果

2026-11-06 用户更正：脚本节点不是带编辑稿、版本和发布功能的工作区。此决定取代 ADR 0012 中脚本版本、编辑稿和显式发布的设计；制作台等后续范围不变。

点击生成即在事务中创建一个新的文本节点和来源连线。后台任务与结果节点固定关联，重发原请求返回同一结果，不重复创建。正文流式显示在文本节点，脚本节点只显示指令、参考、模型、运行和停止状态。每次重新生成创建新文本，不覆盖此前结果。

完成、停止或失败后自动保存已经收到的文字；直接在文本节点编辑，不需要发布。活动任务期间文本编辑暂不可用，防止流覆盖人工修改。旧版本的已保存原稿／编辑稿转换为文本结果，旧表不删除；已存在的文本不重复创建。删除结果节点后迟到任务不会复活它。

脚本到文本的连线表示结果来源，不将脚本要求当作正文，也不让后续修改脚本要求使旧结果下游失效。文本完成落库后按正常文本输入变化规则通知下游，不自动生成下一阶段。

移除版本列表、独立编辑稿和发布 UI、API 与助手工具。后台任务身份、幂等、原始输入快照仍用于恢复与排错，不作为用户的版本管理功能。

指令选择显示自由创作、写剧本、拆分镜、提取素材四张紧凑卡片，包含用途说明；指令正文可展开调整。保持浮动控制台布局与参考能力。
