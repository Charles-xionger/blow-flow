# 记录 Agent 画布操作，首版直接覆盖同一内容的并发编辑

先迭代画布的 undo/redo 和操作记录，再开发 Agent 接入；优先评估成熟方案。一次人工拖动、一次连续文字编辑和 Agent 的一次完整创作步骤分别形成可撤销操作或批次，内部操作仍逐条记录。现有快捷键占位不足以承担这一行为，需要将人工编辑与 Agent 修改的历史和冲突规则一并设计。

Agent 通过 MCP 接入画布操作能力，每一步的状态均需持久化，不能仅保存在模型上下文。操作记录与可撤销历史的具体存储方式和媒体保留期限待设计；MCP 是工具接入协议，持久化状态与画布规则由应用维护。

MCP 首版仅供应用内创作助手使用，暂不向外部客户端开放项目访问与操作。

2026-11-04 调整：首版不引入人工冲突裁决及依赖操作暂停恢复流程。任务发起后，若用户修改了 Agent 随后要写入的同一内容，允许 Agent 直接覆盖，操作仍进入持久历史供撤销与追溯。此决定替代原先“暂停冲突部分，由用户选择是否覆盖”的约定，以简化首版交互。它不授权使用旧的整张画布快照覆盖无关编辑，也不取消生成前的 HITL 确认。

若目标节点在执行期间已被删除，跳过对该节点的写入并向用户说明，不自动恢复节点。已提交的生成结果仍保存到任务记录。直接覆盖只适用于仍然存在的目标内容。

撤销后发生新的内容编辑时，清空当前可重做分支；此前的操作记录仍保留供追溯，不因 redo 失效而删除。历史记录与可直接重做的操作集合因此需要分别表达。

首阶段覆盖节点增删、移动、尺寸调整、内容与参数编辑、连线、分组、复制、导入和素材引用修改；选择状态、视口缩放与任务进度不进入内容撤销栈。连续文字输入合并为一步，编辑器内撤销与画布撤销需明确交接，避免同一次修改被撤销两遍。

已完成的历史首阶段只交付现有画布的撤销、重做和持久操作历史，保留现有保存版本检查；未实现或模拟验收 Agent 步骤运行状态、MCP 接入或人工冲突裁决。Agent 阶段采用本记录更新后的覆盖规则。

已有项目以升级后的当前内容作为初始检查点，从此记录历史，不推测或重建升级前未保存的操作。历史需跨刷新与关闭页面保留。

撤销删除节点恢复节点和已有素材，不自动重新提交此前已取消的生成任务；redo 恢复既有内容，不重新调用模型。已提交任务继续跟踪并保存结果，但迟到结果不能强行写回已删除的节点。现有人工生成任务保留原有过期结果与冲突保护；Agent 写入仍存在的目标内容时，采用上述首版覆盖规则。重新生成由用户明确发起。
