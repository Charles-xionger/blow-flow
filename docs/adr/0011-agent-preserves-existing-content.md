# 创作助手不改写用户已有的节点内容，生成结果不覆盖已有结果

一次事故中，创作助手新建节点的操作屡次失败，又看不到失败原因，于是改写了一个已有图片节点的提示词。用户随后在生成确认中同意了生成，原图被覆盖。为此确定以下三条规则。其中前两条在工具层强制执行，不只依赖提示词，因为模型在工具失败后会自行绕开限制。

1. **默认新建，不改写已有内容。** 创作助手只能修改本轮助手任务中新建的节点的内容和参数，包括提示词、模型、文本、参考素材和生成尺寸。其他节点（包括创作助手在之前任务中新建的节点）属于用户，只有以下两种情况可以修改：用户在本轮通过引用点名了该节点，或者用户在本轮的提问中确认了修改。确认只对该节点和本轮任务有效。移动、调整大小、连线和分组不改变节点内容，因此不受这条规则限制。
2. **生成结果不覆盖已有结果。** 创作助手发起的生成，如果目标节点已有结果，确认时会在原节点旁新建一个同类节点承接结果，复制原节点的参数和上游连线；生成确认会写明“将新建节点”。用户明确要求“重新生成”时同样如此。原因是：用户可以自己删除不需要的旧图，删除也能撤销；而被覆盖的结果无法找回。用户在节点控制台中手动发起的生成保持原有行为。
3. **剧本先停在文字阶段。** 如果用户只要求写故事或剧本，没有明确要求出图或出视频，创作助手把剧本写入画布上的文本节点后结束本轮任务，并建议下一步。它不使用持久提问来等待用户，因为等待中的提问会占住项目，导致同一项目无法开始新任务。这条规则替代此前“不强制剧本到分镜流程”的提示词约定。

本记录收窄了 ADR-0009 中“直接覆盖”的适用范围：直接覆盖只适用于创作助手按本记录有权修改的内容。
