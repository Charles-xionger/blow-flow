# 平台统一配置模型接入，创作助手在服务端后台执行

创作助手采用 PI Agent 作为基座，首版先通过 Gemini 跑通侧栏对话、剧本生成、分镜拆分与画布修改；火山引擎和阿里云随后接入。PI 的具体包组合及版本尚待集成验证。

平台连接及凭据从创作用户设置迁出，由管理员在平台配置中统一管理；创作用户只需选择调用的模型，不自行配置供应商连接和凭据。此决定扩展 ADR-0001 的接入范围，将创作助手所需文本能力纳入本次工作；现有素材生成任务继续遵循 ADR-0002。

创作助手在服务端后台执行，用户关闭画布或断开网络不会停止运行，重新打开后可恢复消息与画布结果。运行生命周期不依赖浏览器连接。

需要用户回答或确认时，持久保存等待状态；关闭页面不视为同意，不超时自动批准。重新打开后，用户可以继续回答、修改或取消。

停止创作助手会停止后续规划与工具调用，并取消本轮尚未提交供应商的生成任务。已提交的任务继续跟踪并保存结果；已完成的画布修改保留，用户需要时另行撤销。停止执行不等于回滚已完成内容，也不承诺撤回供应商已接收的任务。

首版同一项目同时只运行一个 Agent 任务。运行期间的新消息用于补充或调整当前任务；独立的新任务在当前任务完成或停止后开始。不同项目可以分别运行任务。

后台服务重启后恢复消息、步骤和等待状态，中断的 Agent 任务显示为待继续，由用户点击继续；首版不要求任意步骤全自动断点续跑。已提交的图片、视频任务自动恢复查询，不以重新提交代替恢复。等待中的问题和生成确认仍需用户回答，不因重启自动批准。

一批生成部分失败时保留成功结果，说明失败原因，由用户决定是否重试失败项；Agent 不自行反复生成，也不擅自换模型重新提交。状态查询及重试保存已有产物可自动进行，重新调用模型生成需用户明确确认。
