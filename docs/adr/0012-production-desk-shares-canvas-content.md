# 制作台与画布共用创作内容，流程由用户逐阶段推进

脚本节点承担语言模型创作与拆解，文本节点以用途标记承载创意、剧本和分镜等产物；制作台提供角色、场景、道具和分镜列表的集中操作入口，与对应画布节点共用内容、生成状态和结果。选择共用内容而非维护独立素材副本，是为了让制作台内生图与画布上修改始终指向同一份素材；代价是条目与节点的关联、删除和重新拆解必须有明确规则。

制作台以可展开为全屏的大弹窗打开，角色、场景、道具采用卡片，分镜采用列表，并可定位到对应画布节点。分镜文稿与逐镜头条目分开表达，修改文稿后提示重新同步，保留已有素材和人工修改；生成清单后先查看、编辑，再选择条目展开为画布节点。

用户逐阶段运行，创作助手也可创建、连接和批量执行节点。上游修改只提示下游输入已更新，不自动重新生成或覆盖已有结果；生成结果的发布与重新拆解规则见下文。

音频节点首版只支持上传与试听，作为支持音频参考的视频模型的输入。初步观看节点仅按接入顺序连续播放关联视频，并允许拖动调整顺序，不承担裁剪、配音混合或导出；不在本次范围内接入声音生成或声音库。

脚本节点提供自由创作、生成剧本、生成分镜和提取角色／场景／道具等任务预设，预设提供创作指令与输出要求，用户可补充要求并修改指令；模型选择与任务独立。所有连入的参考节点默认参与生成，控制台展示参考列表，并支持在创作要求中引用节点；所选模型不支持参考图片时明确提示，不得静默忽略后让用户误以为已理解图片。

生成结果先在脚本节点内流式展示，完成后可修改，再选择创建文本节点或创建／更新制作台。重新生成保留上一版，不自动覆盖已发布的文本节点；再次发布时由用户选择更新原节点或创建新节点。

剧本或分镜重新拆解时，先展示新增、修改、移除的差异，由用户选择应用范围。场景描述改变时保留已有场景图片并标记需要更新；镜头从分镜列表移除时保留已生成的视频节点。无法可靠判断角色或镜头对应关系时，由用户确认匹配，不自行覆盖。

脚本生成采用后台执行，刷新页面或关闭画布后继续，重新打开可恢复结果；用户可主动停止，停止后保留已生成内容并标记未完成，允许编辑或重新生成，不将中断内容当作完整结果发布。运行中的视觉反馈采用成熟库或现成素材提供的粒子类动态动画，不采用普通转圈，也不自行构建动画引擎。初次生成在空白展示区居中显示动画，正文开始返回后将动画缩到顶部并持续展示正文；重新生成时可切换查看上一版，避免遮罩挡住内容。动画配合真实阶段文字，不表示供应商的真实进度百分比；具体库与粒子素材尚待选定。

制作台提供统一视觉风格和默认图片／视频模型，各条目可单独覆盖设置；支持单项生成和勾选批量生成。统一设置的修改只影响后续生成，并提示可能需要更新的现有素材，不自动重新生成。

拆解分镜时自动识别并关联每个镜头使用的角色、场景和道具，允许用户手动调整；多个镜头中的同一角色复用同一角色素材。生成视频前展示实际使用的图片、音频和镜头描述，并明确提示缺少的素材。

每个镜头支持两条视频生成路径：先生成分镜图，再以该图生成视频；或直接以角色、场景、道具图片作为参考生成视频。入口随所选模型的实际能力开放，由用户选择并发起，首版不自动连续执行后续生成；创作助手发起生成仍遵循既有生成确认规则。

删除制作台只删除整理入口，移除角色、场景、道具或镜头条目只解除其关联，保留画布上的素材节点及已生成的图片、视频和上传音频。删除实际素材节点必须使用明确的删除节点操作；若提供“同时删除画布节点”，必须作为显式操作，不随整理条目的移除默认执行。

音频节点不引入文生声音、台词分段、说话角色关联或角色默认音色管理；声音生成与声音库均留待后续迭代。上传的音频可作为支持音频输入的视频节点的参考素材。

用户通过交互原型选择方案 A：脚本节点在画布中使用下方浮动控制台。控制台参考用户提供的 LibTV 截图，采用宽幅深灰圆角面板，顶部放置带编号的参考素材缩略卡，中央保留大面积创作输入，左下选择语言模型，右下发起／停止生成；任务预设和指令编辑收进紧凑入口，并提供展开输入区的操作。右侧常驻面板与独立工作台不作为默认布局。原型来源为 `prototype/script-desk` 分支，正式实现不直接合入原型代码。

第一阶段只交付脚本创作闭环：连接参考、选择任务和模型、后台流式生成、停止与恢复查看、编辑结果、发布文本节点。验收场景为使用真实模型从创意生成并修改剧本，再将剧本文本连接到另一个脚本节点生成分镜文稿；制作台和下游素材生成留到后续阶段。

每次点击生成时固定本次参考内容、创作要求、任务指令和模型，并保存以便回看结果来源。生成期间上游内容的修改不影响本次输入，只提示参考已更新，下一次生成才采用新内容。同一个脚本节点同时只运行一个生成任务，停止操作须等待任务确认停止后才允许重新生成；不同脚本节点可独立运行。

每次生成分别保留模型原稿和用户编辑稿，发布到文本节点的是用户选择的编辑稿。重新生成创建新版本并保留旧版本；首版提供简单的版本列表、查看和选用，不提供逐字差异比较。

关闭浏览器不停止脚本后台任务；后台进程异常则保留已持久保存的部分正文并标记生成中断，不承诺接续原生成流，也不自动重新调用模型。用户明确重新生成时创建新版本，旧版本和部分内容保留。

再次发布前检查目标文本是否在上次发布后被修改。若已修改，阻止直接覆盖，展示冲突提示并允许查看当前文本，再由用户明确选择覆盖或创建新节点；默认推荐创建新节点，保留人工修改。

参考图片与所选模型能力不匹配、或参考素材无法读取时，在调用模型前阻止提交，指出具体参考及原因。用户需更换模型、修复素材或移除参考后再生成；不得仅提示后继续调用，或静默丢弃参考。

新方案淘汰旧“创意描述／分镜生成”节点类型、入口和旧调用流程，统一使用脚本节点，不维持两套节点并行使用。旧提示词迁入脚本节点，已有生成文本保留为文本节点；尽量保留节点位置和有效连线，不自动重新生成，不因淘汰旧功能而删除已有创作内容。

脚本节点作为创作工作区，下游仅使用明确发布的文本节点，不直接读取正在生成的正文、模型原稿或尚未发布的编辑稿。编辑或重新生成脚本不自动改变下游输入；用户明确更新已发布文本时才更新内容，并提示下游输入发生变化。
