# 05: 拖动调整参考素材顺序

**What to build:** 创作者在连接层拖动缩略图调整参考素材顺序。编辑器里的编号、发送文字和传给模型的素材顺序都随之更新。顺序用目标节点连入连线的相对顺序表示，随画布保存。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 拖动缩略图能改变顺序，且不会拖动节点或平移画布
- [ ] 调整后节点引用标签上的编号立即更新
- [ ] 发送文字里的编号和传给模型的素材顺序保持对应
- [ ] 重新打开项目后顺序不变
- [ ] 调整一个节点的顺序不影响其他节点的上游顺序
- [ ] `node --test` 覆盖顺序和编号规则；浏览器测试覆盖拖动排序
