# 09: 迁移文本、创意描述、分镜节点

**What to build:** 文本节点的节点控制台只有提示词编辑器，节点展示区显示文本内容。创意描述和分镜节点的节点控制台有编辑器、配置和运行，没有连接层，节点展示区显示状态和结果摘要。这些节点的内容都使用分段结构，分镜批量生成的文本节点也一样。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 文本节点在节点展示区显示内容，在节点控制台编辑，没有配置和运行按钮
- [ ] 文本节点内容变化后，引用它的节点运行时使用最新内容
- [ ] 文本节点有上游文本时，可以引用并逐层展开
- [ ] 创意描述和分镜节点没有连接层，生成流程不退化
- [ ] 分镜批量生成的文本节点内容正确，且能被其他节点引用
- [ ] 相关测试更新或新增后通过
