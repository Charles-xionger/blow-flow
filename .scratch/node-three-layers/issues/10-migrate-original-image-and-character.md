# 10: 迁移原图、角色节点

**What to build:** 原图和角色节点使用新外壳，但没有节点控制台，所有操作都在节点工具栏。上传和角色功能不退化。

**Blocked by:** 01

**Status:** ready-for-agent

- [x] 两类节点单选且未拖动时显示节点工具栏，不显示节点控制台
- [x] 原图节点可以上传图片，并预览和下载
- [x] 角色节点在节点展示区显示角色信息，现有按钮的功能移到节点工具栏后仍可用
- [x] 连接到下游节点后，下游能正常获得图片或角色
- [x] 原图上传浏览器测试更新后通过

## Comments

- 原图节点工具栏：上传图片（有图后显示“重新上传”）、预览、下载、保存为角色、删除图片。粘贴上传仍在选中时生效；错误显示在节点展示区。原来面板里的“删除图片”和上传按钮都移到了节点工具栏。上传出错时依赖图片的操作不可用，“删除图片”同时清除错误。
- 角色节点工具栏：编辑角色（没有角色时不可用）、打开角色库。展示区里的编辑按钮和“打开角色库”按钮去掉了。
- 下游获得图片或角色由已有的连接层和图生图、图生视频测试覆盖，本票没有改动这部分。
