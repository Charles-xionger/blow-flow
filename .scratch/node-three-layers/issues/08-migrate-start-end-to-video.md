# 08: 迁移首尾帧节点

**What to build:** 首尾帧节点使用三层结构，并保留它特有的能力：区分首帧和尾帧、交换首尾帧、缺图时不能运行。这个节点是验证“特殊内容放进插槽”的例子，不要为它扩展通用配置。

**Blocked by:** 03

**Status:** ready-for-agent

- [x] 外观与其他生成节点一致，拖动节点时控制台隐藏（当前行为缺少这一点）
- [x] 能看出哪张是首帧、哪张是尾帧
- [x] 交换首尾帧后，发送的素材顺序和引用编号对应正确
- [x] 少于两张图片时不能运行，并给出提示
- [x] 任务恢复、重试保存、错误提示不退化
- [x] 相关浏览器测试更新或新增后通过

## Comments

- 交换首尾帧改为调整连接层顺序，首帧总是图片1、尾帧总是图片2，发送顺序、编号和缩略图拖动排序都是同一个来源。旧数据里的 `swapFrames` 字段不再读取，已保存为“交换”的旧节点会按连接顺序显示首尾帧（界面上能看到，可再点一次交换）。
- 首尾帧取连接层的前两张图片（旧实现每个角色只取第一张参考图）。交换是调整节点顺序，所以只有首帧、尾帧各是所属节点唯一的图片时才能交换；角色有多张参考图而占了尾帧或占满首尾帧时，交换不可用，可以拖动连接层排序。
- 这个节点原本就没有任务恢复和重试保存（接口是同步的），这一条按“不退化”勾选，没有新增；错误提示在节点控制台。
