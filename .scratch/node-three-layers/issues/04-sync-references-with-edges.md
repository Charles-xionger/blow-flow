# 04: 连线变化时同步节点引用

**What to build:** 提示词随画布连线变化保持一致。连接文本节点时自动插入它的节点引用；断开连线或删除上游节点时，节点引用变成断开时显示名称的普通文本；单独复制节点时，副本的节点引用变成普通文本。创作者还可以直接在连接层的缩略图上断开连接。

这些规则放在画布 store 内，与连线变更在同一次状态更新中完成，所有使用节点控制台的节点都自动获得。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 连接文本节点时，目标节点提示词末尾追加节点引用；删除这个引用后该文本不再发送，连线保留
- [ ] 断开连线后，节点引用变成 `@名称` 普通文本，不出现失效状态
- [ ] 重新连线后这段文本保持不变
- [ ] 删除上游节点时按断开连线处理
- [ ] 复制单个节点时不复制连线，副本里的节点引用变成普通文本
- [ ] 目标节点未选中、编辑器未挂载时，以上规则同样生效
- [ ] 可以从连接层的缩略图断开连接
- [ ] store 的 `node --test` 覆盖以上数据规则；浏览器测试覆盖缩略图断开和文本转换
