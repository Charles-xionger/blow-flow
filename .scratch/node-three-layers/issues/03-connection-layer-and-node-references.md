# 03: 连接层和 @ 节点引用

**What to build:** 文生图节点的节点控制台显示上游节点缩略图，悬停显示编号和名称。输入 `@` 弹出已连接的上游节点列表，选择后插入带缩略图的节点引用。运行时节点引用展开成发送文字，连接的参考素材全部用于生成。

发送文字规则：图片引用转成 `图片N`；文本引用展开成上游文本节点的当前内容，并逐层展开；展开中再次遇到同一节点时改用名称文本。参考素材按类型分别编号，默认按连线先后，角色节点按图片类编号。

**Blocked by:** 02

**Status:** ready-for-agent

- [x] 连接层显示所有上游节点的缩略图，悬停显示编号和名称；没有上游节点时不显示这一层
- [x] 输入 `@` 弹出列表，可用方向键和回车选择，也可用鼠标选择
- [x] 没有上游节点时，`@` 就是普通字符，不弹出菜单
