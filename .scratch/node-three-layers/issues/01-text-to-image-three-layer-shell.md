# 01: 文生图节点改用三层外壳

**What to build:** 文生图节点变成原型方案 A 的外观：节点工具栏浮在节点展示区上方，节点控制台浮在下方。预览、下载、保存为角色移到节点工具栏，配置和运行移到节点控制台。提示词暂时仍用现有文本框。新外壳与旧外壳并存，其他节点不受影响。

这张票要建立通用的组合式外壳：节点类型只声明展示内容、工具栏操作、配置项和运行方式，显示条件和通用运行区由外壳和节点控制台负责。详见 spec 的“通用外壳”和“视觉”。外观参考 `prototype/node-console` 分支的方案 A，代码需按正式标准重写。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 文生图节点单选且未拖动时显示节点工具栏和节点控制台；未选中、多选、拖动时都不显示
- [x] 打开节点控制台时节点展示区尺寸、连接点和连线位置不变
- [x] 在节点控制台内点击、滚动、选文字不会拖动节点或平移画布
- [x] 节点工具栏可以预览、下载、保存为角色；没有结果时这些操作不可用；文生图节点的图片悬浮按钮已去掉
- [x] 模型和生成尺寸等配置、运行按钮在同一行，只显示当前模型支持的配置
- [x] 运行状态、错误、任务恢复、重试保存在节点控制台内仍然可用，生成中节点展示区显示进度
- [x] 其他节点类型的外观和行为不变
- [x] 现有文生图相关浏览器测试更新后通过，并新增覆盖显示条件的浏览器测试
