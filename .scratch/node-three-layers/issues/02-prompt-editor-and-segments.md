# 02: 文生图提示词改用 Tiptap 和分段结构

**What to build:** 文生图节点的提示词改用 Tiptap 编辑器，并按 ADR 0005 以分段结构保存到画布。创作者写提示词的体验完整可用，运行时发送编辑器里的文字。这张票还没有节点引用，只有文本段，但数据结构已包含引用段。

分段结构的类型形状来自原型：

```ts
type Segment = { text: string } | { ref: string }; // ref 为上游节点 ID
```
