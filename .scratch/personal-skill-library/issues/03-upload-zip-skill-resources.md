# 03: 上传 ZIP 创作技能并按需读取资源

**What to build:** 用户可上传带配套资源的 ZIP 创作技能，创作助手按需读取其中资源，同时系统阻止危险或异常压缩包产生副作用。

**Blocked by:** 02: 上传 SKILL.md 并供创作助手调用

**Status:** ready-for-agent

- [ ] ZIP 支持根目录直接包含 `SKILL.md`，或仅外包一层目录后包含 `SKILL.md`。
- [ ] 每个包必须且只能解析出一个 `SKILL.md`；缺失、多个或更深层的入口均以明确错误拒绝。
- [ ] 拒绝路径穿越、绝对路径、符号链接及其他可逃逸技能包边界的条目，且不留下部分记录或文件。
- [ ] 每个包最多 20 MB、200 个文件，单文件最多 5 MB；压缩前后校验均不能被压缩比绕过。
- [ ] 上传成功后资源清单可在详情中查看，创作助手只在请求对应资源时读取其内容。
- [ ] 脚本文件可以作为普通文本资源保存和读取，但应用、PI Agent 与创作工具均不提供执行入口。
- [ ] ZIP 中的创作技能同样遵循必填 frontmatter、唯一名称、立即可发现和按需加载规则。
- [ ] 覆盖两种合法目录结构、资源读取、限制边界和恶意 ZIP 的自动化测试通过。
