# 02: 上传 SKILL.md 并供创作助手调用

**What to build:** 用户可向个人技能库上传一个合法的 `SKILL.md` 并立即在所有项目中使用；系统只在创作助手实际调用时加载完整指令。

**Blocked by:** 01: 在个人技能库浏览内置创作技能

**Status:** resolved

- [ ] 管理页支持选择并上传单个文件名为 `SKILL.md` 的 Markdown 文件，上传期间和结果均有明确反馈。
- [ ] 上传要求 YAML frontmatter 提供非空、格式合法且唯一的 `name` 和可用于发现的 `description`；错误信息能够指出失败原因。
- [ ] 与内置或用户创作技能重名时拒绝上传，不覆盖旧内容，也不自动改名。
- [ ] 单文件超过 5 MB 或整个上传超过 20 MB 时拒绝上传，不留下部分记录。
- [ ] 上传成功后，创作技能立即出现在个人技能库和 `discover_skills` 中；完整正文只在 `read_skill` 时读取。
- [ ] 上传内容持久保存，刷新页面和重启后台服务后仍可列出并由创作助手读取。
- [ ] 覆盖合法上传、frontmatter 错误、重名、大小限制、持久化及渐进加载的自动化测试通过。
