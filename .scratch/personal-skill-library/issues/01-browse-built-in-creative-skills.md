# 01: 在个人技能库浏览内置创作技能

**What to build:** 用户可从工作空间右上角的“个人空间”菜单进入个人技能库，在独立管理页浏览和查看内置创作技能；创作助手通过同一技能来源继续发现和读取这些内置技能。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [ ] “个人空间”提供“创作技能”菜单项，并可进入独立的个人技能库管理页。
- [ ] 管理页列出 `screenplay`、`storyboard`，展示名称、发现描述、来源和只读状态，并可查看完整指令及资源清单。
- [ ] 内置创作技能不能被删除、覆盖或编辑。
- [ ] 创作助手的技能发现与读取使用和管理页相同的 Skill Registry，现有内置技能行为保持可用。
- [ ] 个人技能库的跨项目个人范围及渐进加载决定记录在领域文档中，且不与现有 ADR 冲突。
- [ ] 覆盖 Registry、管理页入口和内置技能读取行为的自动化测试通过。
