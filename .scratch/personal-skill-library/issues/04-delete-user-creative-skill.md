# 04: 删除用户创作技能并保留任务快照

**What to build:** 用户可从个人技能库删除自己上传的创作技能；删除立即影响新的技能发现与读取，但不会破坏已记录在现有助手任务中的历史内容。

**Blocked by:** 03: 上传 ZIP 创作技能并按需读取资源

**Status:** resolved

- [ ] 用户上传的创作技能提供带名称和影响说明的删除确认，取消确认不会改变任何数据。
- [ ] 删除成功后，技能及其全部配套资源从个人技能库、`discover_skills` 和后续 `read_skill` 中消失。
- [ ] 内置创作技能在界面和服务端均拒绝删除。
- [ ] 已通过 `read_skill` 写入助手任务步骤记录的指令或资源继续作为该任务的历史快照保留，不因删除被改写。
- [ ] 任务此前仅发现但尚未读取的技能或资源在删除后读取失败，并得到可理解的不可用结果。
- [ ] 删除后的同名 Skill 可以重新上传；旧任务记录与新上传内容不发生静默替换。
- [ ] 覆盖确认交互、资源级联删除、内置保护、运行中任务边界和重新上传的自动化测试通过。
