# 01: Agent 侧栏、后台任务与 MCP 接入

**What to build:** 用户在项目侧栏通过 Pi + Gemini 与创作助手对话，助手通过内部 MCP 读取画布和参考素材，必要时提问，并按需使用内置技能。用户关闭页面后任务继续，重开恢复消息及等待事项。本票交付真实内核、MCP 与界面的闭环，画布写入和生成工具分别在后续票加入。

**Blocked by:** None (can start immediately)

**Status:** claimed

依据：[父规格](../spec.md)，ADR-0007、ADR-0008、ADR-0009、ADR-0010。

- [x] 接通 Pi Agent 与 Gemini，明确并验证实际采用的包组合与版本；平台连接和凭据由管理员统一配置，用户可选择可用模型，无需自行填写供应商凭据。凭据不进入客户端消息或工具结果。
- [x] 项目侧栏提供发送消息、查看回复、运行状态、补充要求和停止入口；不把剧本到分镜写成固定流程，也不声称未调用工具的操作已经完成。
- [x] 本票即建立应用内部 MCP 接入，并通过真实工具调用读取当前项目画布的节点内容、参数和连线关系。工具操作绑定当前项目，不向外部客户端开放。
- [x] 用户可引用画布素材或提供参考图，助手能够获得可理解的图像内容及关联上下文，而非仅得到 URL 字符串；参考图已有信息不重复要求用户填写，关键歧义可通过问题、选项或自由文本澄清。
- [x] 提问及回答关联到持久任务，用户可回答、修改或取消；关闭页面、断网和等待超时不自动视为同意，重新打开后仍能处理。
- [x] 提供内置剧本、分镜技能的发现及按需加载：先提供发现信息，命中后读取完整指令，资源按需读取。用户不使用技能也可创作；不实现上传、删除、管理列表或脚本执行。本票先在对话中产出内容，写入画布由第 02 票完成。
- [x] 对话、任务、执行步骤、工具请求身份和结果持久保存；任务生命周期不依赖浏览器连接，关闭页面后可继续运行，重开显示已产生回复和状态。
- [x] 同一项目同时仅一个 Agent 任务；运行期间新消息用于补充或调整当前任务，独立新任务需等待当前任务完成或停止。不同项目互不串消息与任务。
- [x] 停止后不再继续规划或发起后续工具调用，保留已有消息与结果；重复发送或停止请求不重复创建同一操作。生成任务的停止语义由第 03 票扩展。
- [x] 持久执行记录为后续恢复提供依据，不将 Pi 内存上下文作为唯一事实来源；服务重启后的完整“继续”交互由第 04 票交付，不能将正常关页恢复延后到第 04 票。
- [x] 通过公开任务接口，以可控模型输入验证项目隔离、单任务、提问等待、补充消息、停止及幂等行为；浏览器验证侧栏交互、引用素材、关页重开和项目切换。记录真实 Pi/Gemini 集成验证与替代服务测试的区别，不以替代服务通过宣称真实模型已验证。
- [ ] 按仓库测试约定完成类型检查、受影响代码 lint、完整快速测试及所需浏览器回归；本票持久化和路由影响需纳入浏览器覆盖。未完成的真实集成验收明确记录。


## Comments

2026-11-04：实现于 `ticket/creative-agent-01`。新增持久 Agent 任务服务、独立后台 worker、真实 Pi Agent/Gemini 适配器、应用内部 MCP Client/Server（内存传输，无公开端口）、项目画布/参考图读取和内置技能发现/按需加载，以及侧栏对话、模型选择、引用/上传、问题回答/修改/取消和停止。每项目单任务由 SQLite 唯一索引与事务保证，跨项目 worker 并行；请求与工具身份、消息、步骤结果和等待状态保留。后续画布/生成工具可通过 `AgentService.registerTool` 注册，统一经过持久工具执行入口。

实际依赖固定为 Pi Agent Core / Pi AI 0.73.1、MCP SDK 1.32.2、TypeBox 0.34.52；Pi 旧 scope 已 deprecated（上游迁移至 earendil-works），本版本按已安装 API 集成并测试。真实 Pi 循环通过真实 MCP 读取画布，测试检查图像字节实际进入模型上下文；仅模型供应商输出受控。没有调用真实 Gemini、图片或视频生成供应商，因此 Gemini 线上视觉理解、自由工具/技能选择与创作效果仍待人工验收，不能视为已验证。

最终检查：`pnpm typecheck`、受影响新增代码 ESLint 通过；`NODE_OPTIONS=--no-experimental-webstorage pnpm test` 完整快速测试 238/238 通过，5.61 秒。Node 25.2.0 默认 Web Storage getter 会导致既有画布测试恢复失败，首轮未加该选项的完整运行失败并因残留等待终止；确认既有单项在禁用该实验特性后通过，未修改画布代码绕过。
