# 04: 服务重启恢复与连续创作收口

**What to build:** 后台服务重启后，用户重新进入项目可恢复消息、步骤及待处理事项，并主动继续中断的创作；已提交的图片、视频任务继续查询而不重复生成。完成首版跨断网、关页、重启、停止和项目切换的连续创作行为。

**Blocked by:** 03: 图片、视频生成与批次 HITL

**Status:** ready-for-agent

依据：[父规格](../spec.md)，ADR-0002、ADR-0008、ADR-0009。

- [ ] 服务重启后从持久记录恢复消息、步骤、工具结果、生成关联、批准及等待事项，不依赖旧进程内存或客户端缓存才能解释任务状态。
- [ ] 中断的 Agent 任务显示待继续，由用户触发；等待回答或批准的事项保持未决，不因重启自动同意。停止或已结束的任务不自动重启。
- [ ] 用户继续后基于已有步骤结果和最新项目状态续行，不重复已完成画布修改、历史记录或生成提交；重复点击继续、请求响应丢失及进程中断不能创建同项目并行任务。
- [ ] 已提交图片、视频任务自动恢复查询和产物保存，不等待用户继续 Agent，也不以重新生成替代恢复。产物挂接去重，已删除目标不复活。
- [ ] 已批准但未提交的操作只有在 Agent 继续且批准仍匹配时才执行；等待期间新要求或参数变化按原规则重新确认，不能使用过期批准。
- [ ] 恢复后新消息仍用于调整当前任务；任务停止仍阻止后续调用及未提交生成，不丢失已提交任务结果或已完成画布内容。
- [ ] 用户可清楚区分执行中、等待回答、等待批准、待继续、完成、停止和失败，并查看关联结果或原因；同项目单任务及跨项目隔离在恢复后保持。
- [ ] 验证服务重启发生在工具调用前后、画布写回前后、等待批准、生成已提交及产物保存阶段时，不静默重复副作用或遗失已确认结果；提交事实不明确时继续核实而不盲目重试。
- [ ] 完成自由创作组合场景：参考图理解与提问、技能按需使用、节点与参数修改、局部布局、批次批准、图片/视频连续执行、部分失败与确认重试、停止及历史回放；不要求模型每次选择完全一致的内部步骤。
- [ ] 浏览器组合覆盖关页重开、断网恢复、服务重启继续和快速项目切换；确认打开画布实时同步，未打开画布后台执行，不串项目、不覆盖无关编辑。
- [ ] 按父规格逐项核对首版行为与明确排除项，修复集成缺口，不把首版恢复扩展为任意步骤全自动续跑、外部 MCP 或多 Agent 并发协作。
- [ ] 完成类型检查、受影响代码 lint、完整快速测试及完整浏览器回归，验证期间保持应用、测试、配置和环境不变；全量结果与失败后定向复测分别报告。真实供应商生成仍由用户人工验收，保留可执行场景与实际验收状态，不自动发起付费调用。
