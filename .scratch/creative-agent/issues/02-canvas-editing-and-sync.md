# 02: Agent 编辑画布、参数修改与实时同步

**What to build:** 用户通过侧栏要求助手编辑节点、参数、连线或布局，后台执行后打开的画布同步更新数据与展示，关闭后重开仍一致。所有内容修改复用持久历史，用户可撤销、重做并追溯；内置技能产出可落到画布。

**Blocked by:** 01: Agent 侧栏、后台任务与 MCP 接入

**Status:** ready-for-agent

依据：[父规格](../spec.md)，ADR-0007、ADR-0009。

- [ ] 扩展内部 MCP，支持节点与连线创建、读取、修改、移动和删除；工具参数验证目标存在性、当前项目归属及操作合法性，不允许模型绕过应用规则直接写原始存储。
- [ ] 支持节点标题、文本、提示词、模型选择及该模型支持的生成参数修改；按当前模型能力校验值。涉及模型切换、连线兼容性和节点引用时，复用现有画布规则，不产生参数更新但引用关系失效的不一致状态。
- [ ] 用户要求范围内的普通编辑直接执行；只有用户明确要求删除已有内容时直接删除，否则复用提问交互取得决定。生成参数编辑不等于批准发起生成。
- [ ] 后台操作作用于最新项目内容并持久保存，不依赖打开的浏览器执行。浏览器打开时自动同步节点数据、参数控制台、连线与布局，不要求手动刷新；关闭后重开得到相同结果。
- [ ] 后台修改与本地编辑同步时，只覆盖 Agent 要写入的同一内容，保留无关修改；不以旧整张画布快照替换最新内容，不取消保存版本检查，不将响应丢失误作重复执行理由。
- [ ] 目标在执行期间已被删除时跳过写入并说明原因，不自动复活；保留现有人工生成任务过期结果保护。
- [ ] 人工操作与 Agent 操作共用一套持久历史，一次完整创作步骤形成可撤销批次，内部变更可追溯。记录覆盖前的实际内容，撤销可恢复被覆盖内容；重复工具请求不重复修改或新增历史。
- [ ] 撤销和重做跨刷新、关页及项目切换保持一致；任务进度、选择和视口不进入内容撤销栈，撤销/重做不提交生成。生成批准批次与撤销批次不强制一一对应。
- [ ] 内置技能生成的剧本、分镜等可通过通用画布工具落为节点及连线，不将技能绑定为强制流水线。
- [ ] 评估并接入适合当前画布的成熟布局方案，优先考虑 elkjs；Agent 描述布局意图，由确定性代码计算坐标，考虑节点尺寸、连线和分组。
- [ ] 新增内容默认只布局新增节点，在相关节点附近寻找可用位置，不移动已有节点；明确要求整理才调整已有布局，指定选区时只整理选区。一次整理可整体撤销，不影响范围外内容。
- [ ] 通过公开任务及画布接口验证写入、参数校验、批次历史、重复请求、同内容覆盖、无关编辑保留和删除目标；浏览器验证参数控制台实时更新、布局范围、实际节点尺寸、undo/redo、断网重开和项目切换。
- [ ] 按仓库要求完成类型检查、受影响代码 lint、完整快速测试与完整浏览器回归。真实供应商生成不属于本票验证前置条件。
