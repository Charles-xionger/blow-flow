# 04：停止、重开与异常恢复

Status: ready-for-agent

**What to build:** 用户关闭浏览器后后台继续，重新打开可恢复正文；主动停止或后台异常时保留部分文字，不重复调用供应商。

**Blocked by:** [02：真实脚本后台生成与流式展示](02-script-streaming.md)

## Acceptance criteria

- [ ] 浏览器断开不取消已创建的后台任务；重开、重订阅以服务端最新快照恢复正文和状态。
- [ ] 点击停止后进入停止处理中；确认停止前禁止同节点再次提交，服务端也实施约束。
- [ ] 停止尽力取消供应商流，已保存正文保留并标记未完成；旧流的迟到增量不能改变终态或覆盖新任务。
- [ ] 后台进程丢失或租约失效后标记中断，保留已持久化正文；不承诺接续原流，不自动重新调用模型。
- [ ] 生成完成与停止竞争时只产生一致终态；界面与查询结果一致。
- [ ] 网络重发只恢复原请求身份，不创建第二次付费调用；用户明确重新生成才创建新版本。
- [ ] 删除节点后迟到结果不复活节点；已保存任务内容保留。
- [ ] 停止和中断结果可查看、编辑但不作为完整结果发布；相关状态通过公开契约供版本与发布功能使用。

## Implementation context

复用现有持久任务和助手恢复经验，但当前完整消息存储不能代替流式正文检查点。区分浏览器断线和后台执行器中断。

## Validation boundary

以公开服务行为和真实画布交互作为验收边界，遵循规格的 Testing Decisions。沿用用户“不运行测试”的要求，本任务清单不授权执行自动测试或真实付费模型联调。类型、lint 与静态检查可用于实施反馈；未执行项必须如实报告。
