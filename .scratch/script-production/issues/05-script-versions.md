# 05：脚本版本与编辑稿

Status: resolved

**What to build:** 用户能保存并回看多次生成，分别查看模型原稿和编辑稿，重新生成不会覆盖此前修改。

**Blocked by:** [02：真实脚本后台生成与流式展示](02-script-streaming.md)

## Acceptance criteria

- [x] 每个生成请求关联独立脚本版本，版本可回看模型、时间、任务状态和输入快照。
- [x] 模型原稿与用户编辑稿独立保存；编辑稿初始来自生成结果，后续流式保存不能覆盖人工编辑。
- [x] 重新生成保留旧版本与编辑稿，版本列表支持查看与选用，刷新后选择的内容可正确恢复。
- [x] 当前生成中仍可查看上一版，不能把旧版本误写为当前生成的原稿。
- [x] 并发编辑采用现有版本保护，不能通过旧整图快照覆盖另一个窗口的更新。
- [x] 未完成版本保持其任务状态，即使编辑文字也不能自动伪装成模型已完成。
- [x] 版本不会自动清理；首版不做逐字差异比较、自动合并或复杂版本树。
- [x] 此切片能演示生成两版、编辑第一版、重开后回看原稿与编辑稿。

## Implementation context

发布功能通过公开的版本与编辑稿身份读取内容，不依赖组件内存状态；该契约是 06 的前置。

## Validation boundary

以公开服务行为和真实画布交互作为验收边界，遵循规格的 Testing Decisions。沿用用户“不运行测试”的要求，本任务清单不授权执行自动测试或真实付费模型联调。类型、lint 与静态检查可用于实施反馈；未执行项必须如实报告。

## Source

[第一阶段规格](../spec.md)；[任务总览](../tickets.md)。

## Answer

- 每个任务身份即脚本版本身份；新增独立 SQLite 编辑稿及选用版本记录，流式正文与画布保存均不能覆盖编辑稿。未编辑稿取本版本已保存原文作为初始内容，首次编辑后独立保存。
- 历史入口展示模型、时间、状态、模型原稿、编辑稿和固定输入快照；选用版本跨刷新保留，可在新任务运行时选看旧版。
- 编辑稿和选用版本均采用事务与修订检查。冲突保留本地文字；本地修改未保存时保持当前编辑器并禁止切换。编辑不更改任务状态。
- 发布公开契约：`getScriptVersionService().getPublishableDraft(canvasId, nodeId, versionId, expectedDraftRevision)`，返回含 `draft`、`draftRevision` 与原始 `text` 的版本；校验当前选用、完成状态和编辑修订。发布方在同一 SQLite 事务中调用。
- 验证：TypeScript 类型检查及受影响文件 ESLint 通过。遵守用户要求，未编写或运行自动测试，未调用付费模型；两版生成及重开场景尚未经浏览器或真实供应商验证。
