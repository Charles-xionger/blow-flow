# 05：脚本版本与编辑稿

Status: ready-for-agent

**What to build:** 用户能保存并回看多次生成，分别查看模型原稿和编辑稿，重新生成不会覆盖此前修改。

**Blocked by:** [02：真实脚本后台生成与流式展示](02-script-streaming.md)

## Acceptance criteria

- [ ] 每个生成请求关联独立脚本版本，版本可回看模型、时间、任务状态和输入快照。
- [ ] 模型原稿与用户编辑稿独立保存；编辑稿初始来自生成结果，后续流式保存不能覆盖人工编辑。
- [ ] 重新生成保留旧版本与编辑稿，版本列表支持查看与选用，刷新后选择的内容可正确恢复。
- [ ] 当前生成中仍可查看上一版，不能把旧版本误写为当前生成的原稿。
- [ ] 并发编辑采用现有版本保护，不能通过旧整图快照覆盖另一个窗口的更新。
- [ ] 未完成版本保持其任务状态，即使编辑文字也不能自动伪装成模型已完成。
- [ ] 版本不会自动清理；首版不做逐字差异比较、自动合并或复杂版本树。
- [ ] 此切片能演示生成两版、编辑第一版、重开后回看原稿与编辑稿。

## Implementation context

发布功能通过公开的版本与编辑稿身份读取内容，不依赖组件内存状态；该契约是 06 的前置。

## Validation boundary

以公开服务行为和真实画布交互作为验收边界，遵循规格的 Testing Decisions。沿用用户“不运行测试”的要求，本任务清单不授权执行自动测试或真实付费模型联调。类型、lint 与静态检查可用于实施反馈；未执行项必须如实报告。
