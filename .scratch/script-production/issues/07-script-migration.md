# 07：旧节点迁移与完整链路收口

Status: ready-for-agent

**What to build:** 用户已有创作内容迁入新脚本／文本结构，新旧项目均可使用真实的创意到剧本再到分镜文稿链路，旧产品入口被移除。

**Blocked by:** [03：参考输入与创作任务预设](03-script-inputs.md)；[04：停止、重开与异常恢复](04-script-recovery.md)；[06：发布文本与冲突保护](06-script-publishing.md)

## Acceptance criteria

- [ ] 旧提示词迁入脚本节点，旧生成文字保留为文本节点，已有文本产物不被重复创建。
- [ ] 尽量保留节点位置和有效连接；需要旧输出的下游转向已发布文本，不读取未发布脚本内容。
- [ ] 迁移覆盖服务端画布、本地草稿、恢复和导入入口；重复迁移幂等，不重复生成节点。
- [ ] 迁移不调用供应商、不重跑素材、不凭空补造缺失内容，不删除已有作品。
- [ ] 最终移除旧创意描述／分镜生成类型、入口和旧调用路径；不保留两套产品入口。
- [ ] 创作助手认识新节点，使用一致的创建、连接和发布服务；遵循已有内容所有权与冲突保护，不绕过人工发布边界。
- [ ] 最终闭环可演示：创意文本 → 脚本生成剧本 → 编辑并发布 → 第二脚本生成分镜文稿 → 发布分镜文本。
- [ ] 停止、恢复查看、版本保留、参考校验、发布冲突和正式控制台在该闭环中一致生效。
- [ ] 补充运行所需服务、配置、迁移与已知限制说明；生产中不包含原型、模拟结果或布局对比器。
- [ ] 最终报告区分已完成实现、静态检查、未运行测试和未执行的真实平台联调，不把模拟验证当作付费接口验收。

## Implementation context

此前各切片可在隔离集成分支内部短暂保留迁移兼容结构，最终收口必须移除旧入口。制作台、音频和视频观看仍不属于本任务。

## Validation boundary

以公开服务行为和真实画布交互作为验收边界，遵循规格的 Testing Decisions。沿用用户“不运行测试”的要求，本任务清单不授权执行自动测试或真实付费模型联调。类型、lint 与静态检查可用于实施反馈；未执行项必须如实报告。
