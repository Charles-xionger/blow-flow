# 07：旧节点迁移与完整链路收口

Status: resolved

**What to build:** 用户已有创作内容迁入新脚本／文本结构，新旧项目均可使用真实的创意到剧本再到分镜文稿链路，旧产品入口被移除。

**Blocked by:** [03：参考输入与创作任务预设](03-script-inputs.md)；[04：停止、重开与异常恢复](04-script-recovery.md)；[06：发布文本与冲突保护](06-script-publishing.md)

## Acceptance criteria

- [x] 旧提示词迁入脚本节点，旧生成文字保留为文本节点，已有文本产物不被重复创建。
- [x] 尽量保留节点位置和有效连接；需要旧输出的下游转向已发布文本，不读取未发布脚本内容。
- [x] 迁移覆盖服务端画布、本地草稿、恢复和导入入口；重复迁移幂等，不重复生成节点。
- [x] 迁移不调用供应商、不重跑素材、不凭空补造缺失内容，不删除已有作品。
- [x] 最终移除旧创意描述／分镜生成类型、入口和旧调用路径；不保留两套产品入口。
- [x] 创作助手认识新节点，使用一致的创建、连接和发布服务；遵循已有内容所有权与冲突保护，不绕过人工发布边界。
- [ ] 最终闭环可演示：创意文本 → 脚本生成剧本 → 编辑并发布 → 第二脚本生成分镜文稿 → 发布分镜文本。
- [x] 停止、恢复查看、版本保留、参考校验、发布冲突和正式控制台在该闭环中一致生效。
- [x] 补充运行所需服务、配置、迁移与已知限制说明；生产中不包含原型、模拟结果或布局对比器。
- [x] 最终报告区分已完成实现、静态检查、未运行测试和未执行的真实平台联调，不把模拟验证当作付费接口验收。

## Implementation context

此前各切片可在隔离集成分支内部短暂保留迁移兼容结构，最终收口必须移除旧入口。制作台、音频和视频观看仍不属于本任务。

## Validation boundary

以公开服务行为和真实画布交互作为验收边界，遵循规格的 Testing Decisions。沿用用户“不运行测试”的要求，本任务清单不授权执行自动测试或真实付费模型联调。类型、lint 与静态检查可用于实施反馈；未执行项必须如实报告。

## Answer

已完成生产入口收口与迁移实现：删除旧产品枚举、组件、侧栏入口和同步业务 API；迁移统一覆盖服务端读写、本地草稿、旧 localStorage、导入、恢复副本、直接加载以及撤销／重做。保留节点位置、提示词、已有文本、原始镜头与连线档案；无历史产物证据且确有存储描述时才创建确定身份文本。有历史删除证据或部分现存产物时不推测重建缺失内容。多个真实产物向有效下游展开连接，不生成聚合正文。迁移不调用模型。

未确认的本地保存请求保持原身份和 payload，服务端使用原摘要接收后转换；后续升级草稿另用新身份。历史的活动状态逐步迁移，原审计操作不删除。复制／导入／恢复清除脚本提交、发布、任务与版本来源关联。迁移档案可在正式脚本控制台中查看和复制。

助手目录识别脚本参数及真实语言模型配置，创建／连接沿用 edit_canvas。read_script 读取持久版本；publish_script 通过共享发布服务，持久展示并确认本次正文和目标，事务内校验执行租约和精确发布授权，并保留已有目标的冲突／删除保护。跨恢复调用的发布身份由确认记录固定，不因新工具调用 ID 重复创建。普通助手编辑不能绕过已发布目标的冲突边界。

运行配置、迁移规则、已知限制与待人工执行步骤记录于 [脚本创作与迁移](../../../docs/SCRIPT_CREATION.md)。勾选项表示实现完成，不表示真实平台验收。真实链路演示仍未执行，因此保留该验收项未勾选。

静态验证：`pnpm typecheck` 通过；全部变更 TS/TSX 文件定向 ESLint 通过；`git diff --check` 通过。旧类型／旧 API 静态搜索仅剩迁移读取与历史字段展示。遵守用户要求，未编写或运行自动测试，未发起付费模型调用；浏览器迁移回归、实际停止恢复竞争与真实平台端到端联调仍待执行。
