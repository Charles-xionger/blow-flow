# Script production review and fixes

Reviewed implementation: `2d3af5f...993a489`; fixes on `implement/script-review`, based on `integration/script-production` at `993a489`.

The independent [spec review](reviews/spec.md) and [standards review](reviews/standards.md) found four issues. All four have source fixes:

- **P1, published text mutation through connections:** [CanvasAgentService](../../lib/agent/canvas.ts) checks published targets after reference synchronization, comparing both stored prompt segments and expanded text. This also catches upstream edits/deletions that change retained published targets. Failures occur inside the transaction before canvas/history/receipt persistence, so a batch cannot partially apply. Outgoing published-text connections remain available when they do not mutate a published target. The shared [publishing service](../../lib/script/publishing.ts) supplies an explicit internal publication scope after its ownership and revision checks, permitting intended publication and downstream propagation. No request ID prefix grants privileges. Manual canvas edits retain their existing behavior.
- **P2, local drafts lost on console unmount:** [pending draft store](../../store/useScriptDraftStore.ts) owns text and expected revision outside the console, indexed by canvas/node/version. Each draft has a versioned browser-storage key for refresh recovery; separate keys avoid overwriting another node's pending edits from another tab. The [version panel](../../components/nodes/shared/ScriptVersionPanel.tsx) restores and pins the pending version, blocks publication/version switching until save or explicit discard, and retains conflicting/failed-save text. A late save does not erase newer local typing. Browser-storage failures show a visible warning while memory retains edits. Concurrent editing of the same local draft across tabs is not a merge facility; server revision conflicts remain enforced.
- **P2, full originals in reference thumbnails:** [ScriptInputs](../../components/nodes/shared/ScriptInputs.tsx) uses `CanvasPreview compact`, following [ADR 0006](../../docs/adr/0006-canvas-preview-cache.md). Frozen generation references still use original image identities.
- **P3, duplicated Gemini image preparation:** [text adapters](../../lib/ai-services/text/index.ts) share image content-parts preparation, including embedded-image parsing, signal-aware remote fetch, MIME fallback and base64 conversion. Synchronous retry behavior and single-attempt streaming behavior stay separate.

These changes enforce the existing [specification](spec.md) and [ADR 0011](../../docs/adr/0011-agent-preserves-existing-content.md)/[ADR 0012](../../docs/adr/0012-production-desk-shares-canvas-content.md) publication boundaries. The reference-sync finding demonstrates that some connections do mutate content; the new guard handles that case without prohibiting topology-only operations.
