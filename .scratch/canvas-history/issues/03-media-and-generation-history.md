# 03: 素材与现有生成任务的撤销协调

**What to build:** 用户撤销素材引用修改或带生成任务节点的删除时，可以恢复内容，同时保留正确的生成任务状态。历史不重复复制大文件，undo/redo 不重新提交生成，迟到结果不复活已删除节点。本票针对已有图片与视频生成任务，不依赖未来 Agent。

**Blocked by:** 02: 画布结构操作的批次撤销

**Status:** ready-for-agent

- [x] 上传后挂接素材、替换、移除、排序与已有素材相关设置可撤销、重做；恢复的是已保存内容与引用，不重新上传或生成。
- [x] 历史使用可持久解析的原始素材引用，不依赖预览缓存、临时 Blob URL 或平台临时下载链接；不在每一步历史中复制二进制内容。
- [x] 已有导入或历史内容中的内嵌媒体有明确兼容处理，升级后可显示并恢复，不静默丢失素材。
- [x] 首版不自动裁剪用户历史；应用不得删除仍被保留历史引用的原始素材。缺失原始文件时明确提示，节点其余内容仍可恢复，不以预览图冒充原素材。
- [x] 删除节点时，未提交生成按现有规则取消，已提交生成继续跟踪并保存结果；撤销删除不重新提交已取消任务。
- [x] 恢复节点正确协调本地待发送删除请求、服务端删除状态与生成任务关联，避免界面恢复但后台仍错误处理节点身份。
- [x] 已提交任务迟到结果不得复活已删除节点，不覆盖已经改变的内容或更新任务的展示；保留可追溯结果，复用现有任务查看与恢复行为，不新增人工冲突裁决。
- [x] redo 重新应用已保存内容，不重新执行付费请求；生成进度、轮询和转存状态不会占满内容撤销栈，也不会因恢复旧内容而倒退任务事实。
- [x] 失败、取消、待核实、转存失败等状态遵循现有生成任务规则；恢复或重试保存不能变相创建新生成。
- [x] 验证删除排队任务后撤销、删除运行任务后结果迟到、断网删除后撤销、素材替换与刷新恢复，以及重复 redo 不增加平台提交次数；使用受控生成适配验证，无需真实付费调用。
- [x] 不改变项目回收站和永久删除的既定行为，不实现 Agent、MCP 或人工覆盖确认流程。


## Comments

2026-11-04：完成素材与生成任务的撤销协调。上传完成后的素材挂接、替换、移除、参考素材排序和原声设置进入统一内容历史；一次多文件上传和参考素材移除各形成一个步骤。异步上传和旧生成接口使用操作身份与内容版本检查，删除、恢复、切换项目、再次上传或修改内容后，过期响应不能覆盖当前节点。

内嵌图片/视频/音频在历史的 assets 表中各保存一份，操作补丁引用素材身份；重开、undo/redo 时恢复原始内容，兼容旧历史。没有历史裁剪或原始文件删除逻辑，移除引用不会删除 OSS 原文件。临时 Blob URL 和预览接口地址不能写作原始素材；旧生成接口转存失败不再返回平台临时 URL 作为成功保存结果。原图/视频无法访问时显示明确提示，保留节点其他内容，不使用预览图代替原文件。

生成任务关联、请求原始绑定版本和最新任务 revision 独立于内容补丁保存。进度、轮询与转存状态不创建内容撤销步骤；结果写回是可撤销内容修改。节点内容、输入连线、参考顺序和上游内容变化会使旧结果失效，结果仍留在任务中并可通过节点控制台查看，继续查询和重试保存沿用原任务。

撤销删除保留画布节点 ID，但恢复后的新生成使用独立执行身份，旧身份的取消 outbox 和服务端删除标记继续有效。排队任务保持取消；运行任务继续跟踪保存，旧结果不覆盖恢复内容。创建响应晚到时保留任务身份供查询，不重新提交。原请求响应丢失时恢复同一请求，保留原始内容绑定；即使新浏览器没有 localStorage 恢复记录，也使用项目中保存的原始绑定。复制、导入和恢复副本统一清理所有执行身份与任务事实。

### Standards
