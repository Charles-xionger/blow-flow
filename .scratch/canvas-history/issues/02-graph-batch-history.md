# 02: 画布结构操作的批次撤销

**What to build:** 用户可以把一次节点、连线或结构操作整体撤销和重做，相关节点、连线、提示词引用与布局同步恢复。复用已有持久历史，不另建第二套撤销栈。当前票完成普通节点的结构操作，生成任务副作用由第 03 票收口。

**Blocked by:** 01: 持久历史基础与基础编辑撤销

**Status:** ready-for-agent

- [ ] 节点创建、删除和批量删除均进入统一历史；一次批量操作形成一个撤销批次，内部变更仍可追溯。
- [ ] 创建连线、断开连线与上游排序可撤销；恢复时继续满足连线类型、引用顺序与无环等现有规则。
- [ ] 删除节点或断开连线引起的提示词节点引用转普通文本，与结构变化进入同一批次；撤销恢复结构和原分段内容，不能只恢复连线。
- [ ] 分组和取消分组可整体撤销，恢复父子关系、位置与尺寸；组内拖动不会破坏全局位置。
- [ ] 复制与导入可整体撤销、重做；redo 复用已保存节点身份和内容，不重新分配 ID 或重新读取导入文件。
- [ ] 复制和导入继续遵循现有节点引用重映射及生成任务关联清理规则，不因历史恢复给副本挂上原节点任务。
- [ ] 非法连接或失败操作不产生半完成批次，不留下孤立连线和重复节点；无变化操作不消耗撤销步骤。
- [ ] 刷新后能撤销、重做上述批次，新编辑仍按既定规则使 redo 分支失效。
- [ ] 在第 03 票完成前，涉及生成任务的操作继续遵循既有取消与恢复约束，不通过直接恢复快照绕过任务删除状态。
- [ ] 验证带引用节点删除、多选批量操作、组内布局、复制重映射、导入后刷新与反复 undo/redo，确保没有状态漂移。
- [ ] 范围仅为现有画布操作；不增加 Agent、MCP 或人工冲突裁决。
