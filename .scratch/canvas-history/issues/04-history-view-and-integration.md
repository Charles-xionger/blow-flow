# 04: 历史查看与现有画布验收

**What to build:** 用户可以查看当前项目的操作批次、内部变更和结果，并理解哪些操作已撤销、重做或不再可直接重做。完成现有画布操作入口的覆盖与组合验收，使历史在刷新、网络中断和项目切换后仍可信。本票不扩展为任意历史版本回滚或分支编辑器。

**Blocked by:** 03: 素材与现有生成任务的撤销协调

**Status:** ready-for-agent

- [ ] 提供项目操作历史查看入口，展示可理解的操作摘要、时间、批次及相关状态；能查看批次内部受影响内容，而不向普通用户堆砌原始补丁。
- [ ] 已撤销、已重做和已失效 redo 分支的记录仍可追溯；界面明确区分历史记录与当前可直接 undo/redo 的操作，不暗示失效分支可一键重放。
- [ ] 历史展示基于持久记录，刷新和项目切换后保持一致；未保存、保存失败与已保存状态不能混淆。
- [ ] 较长历史按需加载或分页，查看历史不要求一次下载全部记录或素材二进制，也不通过删除旧历史换取性能。
- [ ] 检查节点工具栏、节点控制台、快捷键、右键菜单、拖动、连线、复制和导入等现有入口；所有约定的内容修改使用同一历史机制，清除迁移期临时限制。
- [ ] 组合验证编辑提示词、连线、分组、复制、素材替换和节点删除后连续 undo/redo，内容、引用与顺序一致。
- [ ] 验证刷新、关闭后重开、断网重试、响应丢失后的重复提交、快速项目切换，不丢失或重复已确认操作，也不串项目历史。
- [ ] 现有保存版本冲突继续拒绝静默覆盖并保护本地内容；验收不依赖未来 Agent，不建设人工冲突裁决界面。
- [ ] 确认生成进度、视口缩放及选择变化不产生内容历史；redo 不增加模型调用或上传次数，迟到结果不复活节点。
- [ ] 完成适当的类型检查、现有持久化与生成回归测试，以及覆盖实际交互的浏览器验证；记录结果和剩余已知限制。
- [ ] 本阶段仅交付现有画布 undo/redo 与持久操作记录；Agent 运行、MCP、Skill 和模型接入均留待后续。
