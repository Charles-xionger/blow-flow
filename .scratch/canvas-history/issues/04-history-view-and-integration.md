# 04: 历史查看与现有画布验收

**What to build:** 用户可以查看当前项目的操作批次、内部变更和结果，并理解哪些操作已撤销、重做或不再可直接重做。完成现有画布操作入口的覆盖与组合验收，使历史在刷新、网络中断和项目切换后仍可信。本票不扩展为任意历史版本回滚或分支编辑器。

**Blocked by:** 03: 素材与现有生成任务的撤销协调

**Status:** ready-for-agent

- [x] 提供项目操作历史查看入口，展示可理解的操作摘要、时间、批次及相关状态；能查看批次内部受影响内容，而不向普通用户堆砌原始补丁。
- [x] 已撤销、已重做和已失效 redo 分支的记录仍可追溯；界面明确区分历史记录与当前可直接 undo/redo 的操作，不暗示失效分支可一键重放。
- [x] 历史展示基于持久记录，刷新和项目切换后保持一致；未保存、保存失败与已保存状态不能混淆。
- [x] 较长历史按需加载或分页，查看历史不要求一次下载全部记录或素材二进制，也不通过删除旧历史换取性能。
- [x] 检查节点工具栏、节点控制台、快捷键、右键菜单、拖动、连线、复制和导入等现有入口；所有约定的内容修改使用同一历史机制，清除迁移期临时限制。
- [x] 组合验证编辑提示词、连线、分组、复制、素材替换和节点删除后连续 undo/redo，内容、引用与顺序一致。
- [x] 验证刷新、关闭后重开、断网重试、响应丢失后的重复提交、快速项目切换，不丢失或重复已确认操作，也不串项目历史。
- [x] 现有保存版本冲突继续拒绝静默覆盖并保护本地内容；验收不依赖未来 Agent，不建设人工冲突裁决界面。
- [x] 确认生成进度、视口缩放及选择变化不产生内容历史；redo 不增加模型调用或上传次数，迟到结果不复活节点。
- [x] 完成适当的类型检查、现有持久化与生成回归测试，以及覆盖实际交互的浏览器验证；记录结果和剩余已知限制。
- [x] 本阶段仅交付现有画布 undo/redo 与持久操作记录；Agent 运行、MCP、Skill 和模型接入均留待后续。


## Comments

### 2026-11-04 — 实现与审查

- 画布工具栏新增操作历史：批次、内部编辑/撤销/重做、受影响内容均每页 20 条。新操作持久化时间、轻量中文摘要和批次编号；旧记录显示时间未知，不伪造时间或复原不存在的明细。文本摘要截断，素材只描述变更，不加载历史原图。
- 历史状态与当前 undo/redo 序列分开：已应用、已重做、可按顺序重做、失效 redo 分支及无净变更批次均可追溯。没有任意版本恢复或失效分支重放按钮。画布历史复用现有本地保存/同步/错误状态。
- 工作空间项目菜单新增独立服务端历史页 `/canvas/history?project=…`。`GET /api/workflow/:id/history` 分页返回批次、内部操作或受影响内容，不返回补丁、检查点或原始素材；查看不需要下载画布快照。跨页携带服务端版本，不混合不同保存版本；页面明确不包含设备上尚未同步的编辑。
- 项目改名、节点数据、公开节点/连线设置入口统一记录历史，清除字段白名单带来的迁移限制；外部旧客户端内容变更仍保留保护性历史边界。工具栏、控制台、快捷键、右键菜单、拖动、连线、复制与导入均沿用同一 store 历史机制。清空与导入保留现有“创建独立项目”语义，原项目历史不丢弃。
- 自动生成提示词及分镜生成接入已有异步完成保护，删除、撤销或切换项目后不接受过期结果；redo 不重新调用生成或上传。
- 新增组合验收：提示词连续输入、两条连线及排序、分组、复制、素材替换、删除，跨 IndexedDB 重开和项目切换连续 undo/redo；SQLite 保存响应丢失后重复提交不重复推进版本，旧版本写入仍拒绝。浏览器覆盖分页、失效分支、内部操作、离线关闭重开与重试、服务端分页无画布/历史二进制下载。
