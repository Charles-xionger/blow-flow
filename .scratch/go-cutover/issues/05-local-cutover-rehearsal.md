# 05: 完成历史导入与本地切流演练

**What to build:** 在本地以同一创作者账户完成历史数据导入和完整创作链路演练，证明 Go 路径能独立承担项目写入、助手工作和结果交付，并能在异常后安全恢复。

**Blocked by:** 02: 迁移个人技能库的账户归属；03: 补齐创作助手画布操作；04: 补齐创作助手生成与结果交付。

**Status:** ready-for-agent

- [ ] 导入并核对项目、文件夹、画布、素材、脚本任务、助手会话和个人技能库的标识、内容与账户归属；其他用户无法访问。
- [ ] 未完成的旧助手任务保留为中断且只读的历史；旧确认和旧供应商请求不会被重新执行。
- [ ] 本地跑通登录、读取并保存画布、助手对话与操作、生成确认、进度查询和结果查看；图片、视频、脚本及助手固定案例均核对最终保存结果。
- [ ] 演练覆盖重启、重复消息、通知丢失、任务失败、单一权威写入方，以及 Go 已产生新增数据后的停止写入、差异核对与回滚。
- [ ] 形成可复现的演练记录，列出通过项、失败项及生产切流仍需满足的门槛。
