# 02: 迁移个人技能库的账户归属

**What to build:** 创作者登录后管理自己的个人技能库，创作助手按当前用户身份发现和读取技能；历史技能随账户资源迁移，打开旧项目时仍可使用。

**Blocked by:** 01: 整合已完成的 Go 迁移代码。

**Status:** ready-for-agent

- [ ] 用户可以列出、上传、查看和删除自己的技能；内置只读技能仍可发现，不能被覆盖或删除。
- [ ] 创作助手首轮获得可用技能的名称与描述，后续按需读取完整指令和资源；读取遵守用户账户归属。
- [ ] 历史个人技能可导入并核对内容、资源和归属；跨用户读取或修改被拒绝。
- [ ] 重复导入和服务重启不会产生重复技能或丢失技能资源，接口和迁移检查通过。
