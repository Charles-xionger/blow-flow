# 04: 补齐创作助手生成与结果交付

**What to build:** 创作者让助手使用当前支持的图片和视频模型生成内容，先确认目标与输入，再看到真实进度，并在画布中获得可访问的结果。

**Blocked by:** 01: 整合已完成的 Go 迁移代码；03: 补齐创作助手画布操作。

**Status:** ready-for-agent

- [ ] 旧路径当前支持的图片、视频生成模式及参考素材在 Go 路径可用；确认内容包含模型、输入和目标节点。
- [ ] 只有用户批准被冻结的生成请求后才创建任务；取消、画布变化、断线和命令重放不会绕过确认或重复付费提交。
- [ ] 助手可读取任务进度与结果，已交付结果正确保存并附着到仍存在的目标画布内容；目标已删除时保留任务结果但不复活节点。
- [ ] 部分失败、供应商响应不明、Worker 重启和通知丢失有安全恢复行为；固定接口案例核对保存、展示和重复请求。
