# 项目工作空间

用户已确认主要交互，并要求先实现项目列表；主页暂不开发。

## 已确认

- 头部采用“主页 / 工作空间”导航，本次只实现工作空间。主页入口暂不可用并标记即将推出；根地址暂进入工作空间。
- 工作空间集中展示项目，打开项目后进入对应画布；文件夹用于归类项目。
- 提供缩略图卡片和表格列表两种视图，首次默认卡片，记住用户上次选择。
- 首版聚焦个人项目管理：搜索、筛选、排序、文件夹、新建、重命名、移动、删除及批量操作。
- 团队空间和分享权限不纳入首版。
- 文件夹仅一级，项目可在根目录或一个文件夹中，支持移入、移出。
- 自动封面优先使用最近生成成功的图片，其次使用画布已有图片；没有图片时显示统一占位，不提供手动上传封面。
- 删除项目进入回收站，支持恢复和手动永久删除，不自动清空。
- 新建时持久化“未命名项目”并直接进入空白画布，允许在画布顶部改名；空画布也保留。
- 卡片／列表偏好在当前浏览器统一记忆，各文件夹共用，不跨设备同步。
- 功能参考 https://app.tapnow.ai/canvas/projects 。参考页面实测为项目管理页直接打开画布，支持卡片／列表、文件夹与项目筛选、创建／修改时间排序，以及单项和批量管理。

## 实现采用的默认规则

- `/workspace` 管理项目，`/canvas?project=<id>` 打开画布，历史 `/?project=<id>` 链接重定向到对应画布。画布提供返回工作空间按钮，离开前保存当前编辑。
- 默认展示根目录项目和文件夹，文件夹排在项目前；按最近修改排序，可改为创建时间及正反顺序。
- 名称搜索覆盖所有文件夹内的项目；回收站搜索仅覆盖已删除项目。搜索结果显示项目所在文件夹。
- 列表字段：预览、名称、类型、内容数量、创建时间、最近更新；回收站将最近更新改为删除时间。
- 项目支持批量移动、移入回收站、恢复和永久删除；文件夹独立重命名或删除。
- 删除文件夹时，其中的项目（含回收站项目）移回根目录，不连带删除。
- 项目删除不改变既有后台生成执行语义，恢复后可重新进入画布恢复任务状态。
- 永久删除清除项目画布数据，保留最小删除标识以拒绝旧离线写入；不连带删除外部媒体或独立生成任务记录。
- 历史项目无文件夹归属，升级后出现在根目录；历史图片缺少生成时间时按已有节点顺序选择封面，后续保存追踪最新变更的生成图片。
- 管理接口返回持久化摘要，不发送完整节点和连线；重命名和项目批量操作校验版本，冲突时提示刷新，避免覆盖其他标签页编辑。

主页内容、团队和分享留待后续设计。
