# 02: 返回工作空间不受其他项目影响

Status: ready-for-agent
Progress: completed
Priority: P2

**What to build:** 当前画布安全保存到本地后，用户可以返回工作空间；其他项目的删除、冲突或同步失败不阻塞导航。

**Blocked by:** None (can start immediately).

- [x] 其他项目存在删除或冲突草稿时，当前项目仍能返回工作空间。
- [x] 当前编辑在返回前完成本地持久化，未确认的服务端同步可继续重试。
- [x] 本地保存失败时留在当前画布并明确提示，保留编辑现场。
- [x] 返回后重新打开项目仍保留最近输入的内容。
- [x] 工作空间与画布导航的完整流程测试通过。

## Comments

用户已确认拆分并授权实现。与工单 01 无阻塞关系；按优先级顺序执行。

返回前等待当前画布本地持久化，服务端队列改为后台同步。浏览器回归覆盖其他删除草稿不阻塞返回、最近输入保留，以及本地持久化失败时留在画布。

最终验证：124 项单元测试串行通过，55 项浏览器回归通过，类型检查、修改模块 ESLint 与生产构建通过；Standards 和 Spec 复审无剩余问题。并发单测曾出现一次既有 WebSocket 时序用例失败，单独复测及串行全套均通过，未改动生成模块。
