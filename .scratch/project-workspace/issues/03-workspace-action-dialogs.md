# 03: 集中管理项目操作弹窗

Status: ready-for-agent
Progress: completed
Priority: P3

**What to build:** 将每种项目管理操作的标题、输入、说明和提交行为集中维护，减少新增或修改操作时出现不一致的风险，保持用户可见行为不变。

**Blocked by:** None (can start immediately).

- [x] 每种操作的显示内容和请求构建集中在同一处定义。
- [x] 新建文件夹、项目与文件夹改名、移动、删除、恢复和永久删除保持原有行为。
- [x] 输入校验、取消、提交中禁用及失败反馈保持有效。
- [x] 既有完整流程测试通过，补齐尚未覆盖的操作与取消场景。

## Comments

用户已确认将可选维护建议纳入本次实现；它不是两项功能修复的前置条件。

操作配置集中于 `action-dialog.ts`，通用表单由 `WorkspaceActionDialog` 渲染。文件夹名称校验、取消与再次打开的浏览器回归通过。

最终复审补充修复：新建项目先在当前标签页持久化请求，响应丢失并刷新后仍沿用原项目 ID；浏览器回归已验证不会重复创建。

服务端重放已接受的创建请求时先验证回执与删除状态，保留项目当前归属。原文件夹被删除或项目随后移动不影响重试；新请求的无效文件夹仍整笔回滚。对应测试 8/8 通过。最终 Standards 与 Spec 复审均无剩余问题。

最终验证：124 项单元测试串行通过，55 项浏览器回归通过，类型检查、修改模块 ESLint 与生产构建通过；Standards 和 Spec 复审无剩余问题。并发单测曾出现一次既有 WebSocket 时序用例失败，单独复测及串行全套均通过，未改动生成模块。
