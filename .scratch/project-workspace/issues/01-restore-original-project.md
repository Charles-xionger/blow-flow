# 01: 恢复后重新启用原项目

Status: ready-for-agent
Progress: completed
Priority: P1

**What to build:** 用户从回收站恢复项目后，曾观察到删除的浏览器也能重新打开、编辑和保存原画布；未同步的本地内容得到保留。

**Blocked by:** None (can start immediately).

- [x] 已同步项目删除、被本地观察、恢复后，可在同一浏览器继续编辑原项目。
- [x] 存在未同步内容时保留双方内容，并提供明确的恢复选择。
- [x] 迟到读取和保存响应不能撤销更新的删除状态。
- [x] 永久删除的项目仍不能恢复或被旧请求重新创建。
- [x] 公共草稿仓库接口及工作空间到画布的完整流程测试通过。

## Comments

用户已确认拆分并授权实现。沿用项目现有的草稿仓库公共接口和浏览器 → 应用 API → 隔离数据库验收边界。

重新打开删除草稿时读取服务端状态；恢复版本与删除观察标识共同防止迟到响应回退状态。未同步内容保留为冲突供用户选择，恢复成功后重新计算待同步错误，避免旧删除提示残留。新增同浏览器恢复编辑、迟到响应、恢复与普通保存区分、未同步内容保留回归。

最终验证：124 项单元测试串行通过，55 项浏览器回归通过，类型检查、修改模块 ESLint 与生产构建通过；Standards 和 Spec 复审无剩余问题。并发单测曾出现一次既有 WebSocket 时序用例失败，单独复测及串行全套均通过，未改动生成模块。
