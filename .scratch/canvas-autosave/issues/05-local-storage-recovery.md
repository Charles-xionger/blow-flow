# 05: 本地存储故障与恢复

**What to build:** 浏览器无法可靠保存草稿时，用户立即知道本地尚未保存，仍可保留、重试或导出创作；恢复环境后继续正常同步，不发生默认空画布覆盖。

**Blocked by:** 03 — 安全迁移旧 localStorage 草稿。

Status: ready-for-agent

## Acceptance criteria

- [ ] 分别处理 IndexedDB 打开失败或不可用、配额不足、事务中止及 schema 升级被其他标签页阻塞，展示可理解的原因和对应操作，不静默切回 localStorage 或仅服务端保存。
- [ ] 本地事务未完成或失败时不能显示本地已保存或已同步；保留当前内存修改和原持久化数据，不清除未确认同步记录，不提前把该修改发送为已可靠记录的操作。
- [ ] 普通编辑失败后提供重试与导出；升级阻塞时提示关闭占用标签页后重试。数据库重新可用后从最后成功版本与当前内容恢复，不能重复创建或回退内容。
- [ ] 数据库打开失败或恢复未完成时不允许默认空状态被写回。无法恢复内容时保留加载失败视图与重试入口；不把空画布显示成已恢复成功。
- [ ] 迁移失败沿用 03 的原文备份和恢复副本，导出尚未解析的旧备份时按原文保留，不能错误地导出默认空画布代替原数据。
- [ ] 对当前有效画布，导出包含完整可用的节点、连线和项目内容；导出成功不等于服务端同步成功，保存状态不因导出改变。
- [ ] 隐藏页面或退出时只能尽力提交，不新增强制关闭前必达承诺；错误信息明确当前未保存风险，避免反复弹出相同错误干扰操作。
- [ ] 真实浏览器中验证升级阻塞及解除后重试；使用故障注入覆盖打开失败、配额错误和事务失败，断言内容保留且没有虚假成功。
- [ ] 测试恢复后重新保存，通过真实 API 在隔离 SQLite 读回内容；覆盖迁移中失败与普通编辑失败两类入口。
- [ ] 本票可在 03 完成后独立实施，不依赖 04 的多画布调度；相关回归测试及类型检查通过。

## Scope notes

不承诺用户清除浏览器数据、磁盘损坏或本地事务提交前强制关闭后的无损恢复。不引入 Service Worker、后台关页上传、无限版本历史或新的第三方存储服务。
