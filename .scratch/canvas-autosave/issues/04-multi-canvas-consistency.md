# 04: 多画布同步与冲突、删除保护

**What to build:** 创作者在多张画布、多个标签页间切换时，修改始终保存到正确画布与版本；单个项目失败不拖住其他项目，冲突不静默丢内容，已删除项目不会被离线旧请求复活。

**Blocked by:** 02 — 断网与刷新后恢复同步；03 — 安全迁移旧 localStorage 草稿。

Status: ready-for-agent

## Acceptance criteria

- [ ] 切换、新建、导入或当前“清空开启新项目”操作前，保留原画布待提交内容并绑定原身份；普通删除最后一个节点仍更新原项目为空，不被误判为新项目。
- [ ] 多张画布各自持久保存草稿、未确认操作和状态，刷新及切换回来后可恢复；迟到响应不能改变当前画布 ID、内容或不相关项目的状态。
- [ ] 每画布串行，当前客户端全局默认最多两张画布同时同步；错误和退避按画布隔离，一个项目持续失败不会阻止其他项目成功落库。
- [ ] 多标签页更新本地草稿时，在 IndexedDB 事务内原子检查本地版本；陈旧标签页内容不覆盖更新草稿，而保留为可恢复副本并提示。
- [ ] 不同标签页可能重放同一未确认操作，服务端幂等保证只应用一次；不得仅依赖页面内布尔锁来保证一致性。
- [ ] 远端版本冲突暂停该画布自动覆盖，保留双方内容；复用 03 的恢复入口，允许采用服务端版本或另存本地副本，采用远端前保存本地恢复副本。不增加自动合并或强制覆盖。
- [ ] 所有真实画布写入入口遵循版本检查，旧无版本请求不能绕过冲突保护；旧响应只能确认其自身操作，不撤销新的冲突或删除状态。
- [ ] 删除项目以数据库事务保留删除标记并使旧写入失效，历史数据升级安全，列表不显示已删除项目。已存在删除标记的 ID 不允许通过新建路径重新创建。
- [ ] 离线请求遇到远端已删除时停止自动同步并提示，保留本地内容；用户另存副本使用新 ID。重放已成功的历史请求不得改变删除标记，旧成功回执也不得让客户端把已删除项目恢复为当前正常项目。
- [ ] 真实浏览器验证 A 画布请求挂起时切换 B 并保存，再返回 A；A 持续失败时 B 仍成功；两者内容与数据库 ID 均不串写。
- [ ] 两标签页测试陈旧本地修改、同请求重复发送和服务端版本冲突，验证双方内容有恢复入口且服务端无静默覆盖。
- [ ] 断网编辑后在另一客户端删除项目，恢复网络后验证列表和数据库不会复活项目；选择另存副本后只创建新的项目 ID。
- [ ] 执行完整编辑、迁移、离线恢复相关回归，验证生成任务恢复与删除行为未被重新提交任务替代，类型检查通过。

## Scope notes

此票合并已确认的多画布隔离、多标签页/远端冲突和删除保护。依次完成隔离、冲突、删除三个可验证行为，但对外交付一个完整任务；不扩展为协作编辑系统或重做项目管理界面。
